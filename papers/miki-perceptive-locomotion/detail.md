# Learning robust perceptive locomotion — Detail

> 本文件只含 brief.md 没有的可复现细节。所有数据已通过 arXiv TeX 源码（2201.08117）逐项核实，替代旧版笔记的"待核实"标记。
> 勘误沿袭旧示例：训练仿真器为 RaiSim（非 Isaac Gym）；attentional gate 为 sigmoid 逐维门控跳连（非 QK softmax）；"DAgger 式采样"是解读标签，论文原词为"roll out student policy"。

## 方法详解

### 训练管线（三阶段）

1. **Teacher RL**：PPO（自定义实现 rslgym）训练 Gaussian 策略 \(a_t \sim \mathcal{N}(\pi_\theta(o_t = s_t), \sigma I)\)，MLP 主干。随机地形 + 随机扰动 + 随机体坐标系指令 \(\bm{v}_{des}=(v_x, v_y, \omega)\)。特权观测 = 无噪地形测量、摩擦系数、所加扰动。观测先做 running mean/std 归一化。1000 并行环境，每迭代采 250 步。
2. **Student 蒸馏**：同环境，高度采样过噪声模型 \(o^{student}_t=(o^p_t, n(o^e_t))\)。belief encoder（GRU + 门控）+ 动作 MLP（复用 teacher 主干权重初始化）。损失 \(\mathcal{L} = \mathcal{L}_{bc} + 0.5\,\mathcal{L}_{re}\)：BC 为同状态同指令下 student/teacher 动作平方距离；重建为无噪高度采样与特权信息 vs belief 重建值。训练样本由 student 自己 rollout 生成（引 Ross et al. 2011 / Czarnecki et al. 2019，思想同 DAgger——解读）。300 并行环境，每迭代 400 步；TBPTT 截断 10 步，每批 2 epochs，lr 5e-4。前 10 epochs 平地，之后启用自适应地形课程；student 课程因子 \(c_{sk}\) 从 20 epochs 起线性升到 100 epochs 后恒 1.0。
3. **零样本部署**：真机不微调。

### 观测空间（Table S3 逐维核实）

| 通道 | 维度 |
|---|---|
| 指令 \(v_x, v_y, \omega\) | 3 |
| 机体姿态 | 3 |
| 机体速度 | 6 |
| 关节位置 | 12 |
| 关节速度 | 12 |
| 关节位置历史（3 步） | 36 |
| 关节速度历史（2 步） | 24 |
| 关节目标历史（2 步） | 24 |
| CPG 相位信息（每腿 Δφ、cosφ、sinφ、基频） | 13 |
| **外感受：每脚高度采样** | **208** |
| 特权：接触状态 / 接触力 / 接触法线 | 4 / 12 / 12 |
| 特权：摩擦系数 / 大小腿接触 / 机体外力外力矩 / airtime | 4 / 8 / 6 / 4 |

高度采样：每脚 5 圈 \{6,8,10,12,16\} 点、半径 \{0.08,0.16,0.26,0.36,0.48\} m，共 52 点/脚 × 4 脚 = 208 维。

### 动作空间（CPG 结构化）

\(q^{target}_{i\in l} = IK(\mathbf{p}(\phi_l + \Delta\phi_l + \Delta\phi_0)) + \Delta q_i\)。名义足端轨迹 \(\mathbf{p}(\phi)\)：摆动上抬 \([0, \pi/2]\) 三次 Hermite 样条抬 0.2m，落下 \((\pi/2, \pi]\) 对称，支撑相 \((\pi, 2\pi]\) 贴名义站高。

### 网络结构（S6 核实）

- 外感受编码器 \(g_e\)：2 隐层 \{80, 60\} → 96 维（24×4，每脚单独编码后拼接）；特权编码器 \(g_p\)：\{64, 32\} → 24 维
- 主干 MLP：\{256, 160, 128\}，全 LeakyReLU
- belief encoder：GRU 2 层 × 50 隐单元；\(b_t = g_b(b'_t) + l^e_t \odot \alpha\)，\(g_b\)、\(g_a\)（门）各 \{64, 64\}；belief 120 维（96+24），注意力向量 α 96 维，跳连零填充对齐
- decoder 用同款门从 \(b_t\) 重建无噪高度采样与特权信息，仅训练期（算重建 loss）+ belief 内省可视化用

### Reward（S7 逐项核实）

\(r = 0.75(r_{lv}+r_{av}+r_{lvo}) + r_b + 0.003\,r_{fc} + 0.1\,r_{co} + 0.001\,r_j + 0.08\,r_{jc} + 0.003\,r_s + 10^{-6}\,r_\tau + 0.003\,r_{slip}\)

- \(r_{lv}\)：\(|\bm{v}_{des}|=0\) 时 \(\exp(-|\bm{v}|^2)\)；\(\bm{v}_{des}\cdot\bm{v} > |\bm{v}_{des}|\) 给满 1.0（超速不罚）；否则 \(\exp(-(\bm{v}_{des}\cdot\bm{v}-|\bm{v}_{des}|)^2)\)。\(r_{av}\)（yaw）同式
- \(r_{lvo}\)：\(\exp(-3.0|\bm{v}_o|^2)\)，\(\bm{v}_o\) 为指令正交速度分量
- \(r_b\)：\(-1.25 v_z^2 - 0.4|\omega_x| - 0.4|\omega_y|\)（抑制非指令机体运动）
- \(r_{fc}\)：摆动相足底高出周围采样地形不足 0.2m 时罚（防无谓高抬腿，保步态自然）
- \(r_{co}\)：shank/knee 碰撞罚 × 课程因子 \(c_k\)
- \(r_j\)：\(-c_k\sum(0.01\dot{q}^2 + \ddot{q}^2)\)（抑振动）
- \(r_{jc}\)：膝关节阈值软约束（防膝反关节），仅对膝设置
- \(r_s\)：关节目标一阶+二阶差分平滑罚 × \(c_k\)
- \(r_\tau\)：\(-c_k\sum\tau^2\)（省电，τ 来自执行器网络输出）
- \(r_{slip}\)：\(-c_k\sum v_f^2\)（接触足速度罚）

课程因子 \(c_{k+1} = c_k^d\)，d=0.98，每 episode 更新；作用于随机化幅度与部分惩罚项。

### 噪声与随机化（S8 逐项核实）

- 物理随机化：机体/腿质量、初始关节位置与速度、初始机体姿态与速度、躯干外力外力矩、足底摩擦偶发调低（打滑）
- 终止：躯干触地、大倾角、超关节力矩
- 高度采样噪声两类：采样点横向偏移（\(x_p, y_p\)）+ 高度值扰动（\(h_p\)）；作用域三档——每点每步 \(\epsilon_p\)、每脚每步 \(\epsilon_f\)、每 episode 常量 \(w\)；另有间歇离群值 \(\epsilon_{outlier}\)（概率参数 \(z_5\)）。参数 \(z\in\mathbb{R}^{8\times4}\)（每腿 8 分量；注：文中列出的 z 向量只印了 7 项，疑排版并项，不影响结构理解）
- 三工况（nominal / offset / noisy）按 **60% / 30% / 10%** 抽取，每条轨迹**开头与中途各抽一次**；offset 用每脚噪声模拟位姿漂移/可变形地形，noisy 用每点大噪声模拟遮挡/建图失效；offset 与 noisy 的关键分量幅度由 \(c_{sk}\) 课程线性放大
- 地形分格加偏移，模拟植被/深雪地块突变

### Terrain（S4 核实）

rough（Perlin 噪声）、rough discrete、large steps（两档 \(h\in[0,0.4]\)）、grid steps（\(h\in[0.05,0.4]\), \(d\in[0.2,0.7]\)）、stairs（\(d\in[0.25,1.0]\), \(h\in[0.01,0.22]\)；random stair 尺寸乘 \(\mathcal{N}(1.0,0.2)\)）、boxes（≤0.25m）。楼梯用盒子拼装——高度图楼梯边缘不垂直，policy 会钻仿真空子导致 sim-to-real 迁移差（工程教训）。

### 消融（S9 核实）

四变体：GRU gate / GRU no gate / MLP gate / MLP no gate。结论：GRU 全面优于 MLP（MLP 无法重建特权信息）；门结构在 GRU/MLP 上都稳定增益；小噪声下动作差全面更小（rough 0.690±0.40 vs 0.746±0.40），大噪声下两者接近——门在可靠时用外感受、不可靠时不牺牲鲁棒性。台阶成功率（0.8 m/s 指令，100 trials/高度）GRU gate 双噪声档均最优。

## 实现与部署细节

- 仿真：RaiSim，多台 ANYmal-C 并行，集成学习式执行器模型（引 Hwangbo et al. 2019）弥合 sim-to-real；框架 PyTorch
- 部署：ANYmalRobosense Bpearl dome LiDAR **或** 4×Intel RealSense D435，两套传感器配置零微调互换——高程图是传感器抽象层
- GPU 高程图管线 20Hz：Kalman 式更新 + 漂移补偿 + ray casting（并行点云处理，快建图是跟上高速步态的前提）
- policy 50Hz，从最新高程图采样，无图位置填随机采样值

## 实验与泛化过程

- **台阶梯度**：12–36.5cm 木阶，10 trials/档，5 秒内通过计成功。基线 20cm 起前腿频繁卡（后腿也常跟不上）；本方法 30.5cm 可靠——提前抬腿 + 前倾送后腿，主失败模式是侧向绕开而非摔；>32cm 主动犹豫（学到超出物理极限）
- **障碍赛**：20cm 斜台/高台、17cm 高 29cm 深楼梯、20cm 方块堆，pure pursuit 跟径。本方法顺滑通过；基线三处全卡，人工抬推
- **速度**：平地前进/横移 1.2 vs 0.6 m/s；转向 3 vs 0.6 rad/s；20cm 台上差距更大（基线近乎停滞）
- **仿真量化（S2）**：0.7 m/s × 10s，300 trials，4m 无失败计成功；41×41 地形参数网格，grid steps 与 stairs 成功率全面超基线
- **野外**：阿尔卑斯/森林/地下/城市多季节部署零摔；Etzel 山 2.2km、120m 爬升、38% 坡，登顶 31min（人类标牌 35min）、全程 78min（徒步规划器 76min，评级 difficult），仅停机修鞋换电池
- **DARPA SubT**：Cerberus 队默认控制器获冠军；4 台 ANYmal 在 tunnel/urban/cave 探索 1700m+，粉尘/雾/水/烟退化感知下零摔
- **belief 内省（可视化）**：泡沫障碍踩后地形估计下修且离地后保留（循环记忆）；透明亚克力接触后上修；蒙传感器收纯噪声，磕碰修正估计后照样上下楼；滑面识别低摩擦（decoder 可解出摩擦系数）加快步频；位姿漂移毁图期间退回 proprio，图稳后切回

## 对游戏开发的启示

- **CPG 相位残差动作空间**：名义轨迹 + IK + 残差，与游戏动画管线（foot trajectory + IK + 程序化修正）同构，比裸关节位置输出好落地
- **特权蒸馏管线**：仿真特权状态训 teacher → 观测蒸馏 student，物理角色训练标准配方；比直接在 partial-observable 下 PPO 稳
- **门控跳连技巧**：多输入源可靠性不一时逐维开关直通量；训练时对该源加噪声/dropout 即学会开关——可用于多传感器/预测器/玩家输入融合
- **"从历史估不可观测状态"**：游戏对应网络同步延迟下的状态预测、玩家意图估计、物理角色接触/摩擦估计——同一结构换不可观测量
- **不该照搬**：LiDAR/高程图建图与外感受噪声模型整套是为真机传感器不可靠免费，纯冗余
