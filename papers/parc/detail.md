## 方法详解

### 迭代循环（Section 4）

```
D⁰ (14m07s 种子 + 50 变体/clip 空间扩产)
repeat i = 1..4:
  Gⁱ   = 在 D^{i-1} 上续训生成器（上一阶段权重热启动）
  M̃ⁱ   = Gⁱ 在新地形上合成动作（含选择启发式 + 运动学修正）
  πⁱ   = 在 D^{i-1} ∪ M̃ⁱ 上续训跟踪控制器（热启动）
  Mⁱ   = πⁱ 在仿真里跟踪 M̃ⁱ 录制的物理校正动作（多起点重试，取最早成功）
  Dⁱ   = D^{i-1} ∪ Mⁱ
```

- 迭代 1–2：Random Boxes 地形（16×16 格 @0.4m，盒宽 5–10 格，高 ±2m，
  2×2 滑窗 max-pool 消窄缝窄墙），每轮 ~1000 动作
- 迭代 3–4：100×100 手工地形的随机 16×16 切片，每轮 2000 动作
- 动作上限 10s；单 A6000 全程 ~1 个月

### 生成器（Section 5 + Appendix C/D）

- **架构**：MDM 式 transformer encoder。高程图 31×31 → CNN 出 64×16×16 →
  切 64 个 64×2×2 patch → MLP 成 token；目标方向 MLP 单 token；噪声帧每帧
  一个 MLP token；全部加位置编码；输出 token 过 MLP 回干净动作。
- **表示**：0.5s 窗口 = 2 过去帧 + 13 未来帧（相对第 2 帧正则化）。帧特征
  = root 位置(3) + root 旋转(3, expmap) + 关节旋转(J×3) + 关节位置(J×3) +
  接触标签(J)。
- **损失**：ℒ = ℒ_rec + ℒ_vel + ℒ_joint + ℒ_pen
  - ℒ_rec：位置/旋转/接触三分量分开算（旋转用 expmap ⊖，接触 L2）
  - ℒ_vel：位置速度（有限差分）+ 角速度（四元数差分转 expmap）
  - ℒ_joint：预测关节位置 vs FK(root, 关节旋转) 一致性
  - ℒ_pen：身体表面采样点对地形 SDF（盒并集）的穿透量
- **地形合规训练**：10% 概率在随机地形上合成、只开 ℒ_pen、关 ℒ_rec——
  推广到 OOD 高程图不穿透。
- **Blended denoising**：G_blend = s·G(无历史帧) + (1−s)·G(有历史帧)，
  s=0.65（数据扩产）/ 0.5（长程生成）。无历史帧分支：训练时 15% 概率
  mask 掉前两帧 token 的 attention（同权重双条件）。
- **采样**：DDIM stride 5；批量 64 生成 + 选择启发式
  （ℒ_pen + ℒ_contact + 1000×未到终点）选最优；再运动学优化
  （Adam lr 1e-3 × 3000 步；w_reg=1, w_pen=w_contact=w_jerk=1000，
  jerk 上限 1000 m/s³）去抖动/穿透/接触错。
- **高程图增广**（训练期）：随机旋转盒子放地形上，再按预计算的每格
  上下界 clamp——不与动作轨迹相交（非干扰增广）。

### 跟踪控制器（Section 6 + Appendix F）

- **DeepMimic 框架**，Isaac Gym；PPO + GAE(λ)，value 用 TD(λ)。
- **策略网络**：3 FC 层 2048/1024/512。
- **频率**：policy 30Hz，物理 120Hz；动作 = 各关节 PD 目标姿态。
- **观测**：proprio（root 位置/旋转、关节旋转/位置、接触标签）+ 局部
  高程图 + 参考动作未来帧（帧数未给，待核实）；全部相对角色局部系
  （root 原点、x 朝向、z 全局上）。
- **Reward（Appendix F 全表）**：

| 项 | 表达式 | 权重 |
|---|---|---|
| pose | exp[−0.25 Σ w_j‖q̂ ⊖ q‖²] | 0.5 |
| pose velocity | exp[−0.01 Σ w_j‖q̇̂ − q̇‖²] | 0.1 |
| root | exp[−5(‖p̂−p‖² + 0.1‖q̂_root ⊖ q_root‖²)] | 0.15 |
| root velocity | exp[−(‖ṗ̂−ṗ‖² + 0.1‖ω̂−ω‖²)] | 0.1 |
| key body（手+脚） | exp[−10 Σ‖p̂_i − p_i‖²] | 0.15 |
| **contact（双向）** | (1/J) Σ_j [ĉ_j c_j − (1−ĉ_j) c_j] | 1.0 |

- 关节 pose 终止判据 0.7m（脚无终止判据——给物理解留自由度）。
- **接触标签双向**：匹配给分 + 多余接触扣分——自然接触构型的关键项。
- **优先失败采样（Prioritized State Initialization）**：参考 clip 按
  失败率加权多项分布采样（每 clip 下限 0.01 防灾难遗忘）；早停让难
  clip 越来越少被采到的问题由此反转。出处 Won&Lee 2019 / Park 2019 /
  Xie 2022 / MaskedMimic。
- **物理校正录制**：沿动作不同时刻多起点初始化，最早成功到末帧的
  起点录制为数据；sim 自动标注接触标签。

### 地形与路径（Appendix A/B）

- 地形 = 2.5D 盒网格（0.4m 格）。测试地形用 **Random Walk 算法**（与训练
  的 Random Boxes 不同生成器 → 地形生成 OOD）。
- A\*：邻接边高差 ≤2.1m；跳跃边（半径 + 高度窗口 + 线-盒相交查墙）；
  代价 g = 1·d_xy² + 0.15·d_z² + U(0, 0.5)（水平权重高 → 鼓励用爬升
  技能抄近路；随机项出多样路径）。

## 实验与泛化过程

- 生成器评估：100 测试地形 × 32 动作 × 各迭代 = 3200/迭代，只开 blended
  denoising（s=0.65）+ DDIM(5)，**不做**运动学/物理修正——测的是裸生成器。
- tracker 评估：100 动作（经选择启发式选优），成功率 = 从首帧跟到末帧；
  关节误差 = 2048 episode 随机起点均值。
- 数据分布可视化：root 水平位移分布从"大都向前"逐迭代铺开成全向。

## 对游戏开发的启示

（解读，brief 之外）

- **动捕扩产管线**：游戏侧最直接的用法不是 runtime，是资产管线——少量
  高质量核心动捕 → PARC 式循环 → 大量物理合理 + 接触标注的动作数据，
  喂 motion matching / learned MM / 动画库。接触标签由 sim 自动标注
  （手工标 14 分钟已是成本），对 learned MM 尤其值钱。
- **"物理仿真当校正器"是通用模式**：任何生成式动画（扩散/LLM 骨骼码）
  的伪影都可以用"RL tracker 过一遍仿真"来过滤——比后处理规则强，
  因为它只能产生物理上做得到的动作。代价：要有 tracker。
- **接触双向 reward + 优先失败采样**：两个可直接搬进任何
  DeepMimic 系训练的组件，与地形无关。
- **Blended denoising 的教训**（CFG 思想搬到时序生成）：自回归小模型
  过拟合历史帧 → 无视条件——游戏侧任何"历史帧 + 条件"的自回归生成
  （表情/动作/相机）都可能遇到同款退化，mask 训练 + 推理混合是解法。
- **与 lizard parkour 线对照**：同一地形穿越问题的两条解——我们
  （robotics 路线）专家 RL 无动作数据、动作自然性不保；PARC（动画路线）
  小数据 + 生成器 + 物理校正、动作动画级。两边组件可互通：我们的
  parkour 专家轨迹可作 PARC 式 tracker 的参考源；PARC 的接触 reward
  与优先采样可进我们的专家训练。
- **不该照搬**：全管线一个月单卡是科研配置，游戏产线要砍迭代数/动作数
  （论文的消融说明 1 迭代也有大改善）；runtime 角色控制别指望生成器。
