# 腿链几何探测复用指南

用于增轴、改轴、改骨长或改掌形后的几何诊断：先选择已有能力，只补变化影响的覆盖，不另造一套 FK、碰撞或扫描器。本文管复用方法与入口；具体构型、在办动作和结果分别取家族文档、work 与验收记录，不在这里复制读数或参数。

## 先区分三种复用

- **实现复用**：坐标变换、网格判定、边界括号加密等算法可复用，但必须满足输入契约。
- **证据沿用**：输入几何、轴、命名、方法、过滤、配置和覆盖条件仍兼容时，原证据保留原结论；变化只重验受影响部分。文件日期或脚本哈希变化不自动要求全量重跑，须追到实际行为差异。
- **对照复用**：旧机构、旧平掌任务或固定其它轴切片可作为对照，不能把其边界数字迁入新构型，也不能把切片读数扩成完整安全域。

“新轴置零”只证明特定对照姿态或轨迹保留旧运动；不能代替新轴非零、组合运动及动力学验证。

## 通用 precheck 接入与复用

机体预检选 `rl_exp/tools/diagnose/body_precheck.py`，不再复制腿数扫描、FK、碰撞器或另建报告框架；先按模块文档核支持域，再用同目录 `body_precheck_lizard2.json` 看普通数据接线。配置中的真实链、角色、完整关节姿态、根位姿、需求与过滤须重新绑定自身输入，不能只换 naming 或沿用样例判词。

- **已有方法**：`joint_limits`、`self_collision` 为采样几何基线；`end_position`、`ground` 只检查显式位置/平面；`contact_pairs` 仅免正工程间隙，不免相交。`role_consistency` 消费独立角色批准；`source_consistency` 消费独立全 link 姿态；`source_geometry` 消费已有保存重开源枢轴与视觉网格样点。参数、源格式、支持矩阵唯一归模块文档，反例唯一归 `rl_exp/tools/verify/test_body_precheck.py`。
- **源样本接线**：`inputs.source_evidence` 绑定已审样本文件；`source_geometry.params.source_cases` 映射本任务与源快照，完整 q 须一致。源 q 缺项只有显式零复位来源才补零；视觉网格及 blend 从证据中的批准摘要核身份。源对象索引不等于导出索引，最近顶点比较不是一对一随动证明。
- **缺证出口**：源几何样点不替代完整朝向、实体归属/角色独立性或连接区域判据。未知源格式、不支持变换具名拒绝，必需缺证/未执行保持未判；采样覆盖不等于任务通过。不从同一 FK 生成“独立”源姿态，不排除连接对来取得通过。
- **变化复验**：需求/角色重绑受影响行；轴、pivot、树变化涉及全部后代链和组合；网格/归属变化涉及实体对、环境及源样点；新正式导出核新身份与支持域，旧检查点不自动沿用。责任路由取 `work/active/robot-body-precheck.md`，结果只取验收记录。

只有一个本地真实构型时，继续用它接实际需求、消费证据及拒错，不为凑跨构型验收下载/生成或改名复制第二机体。另一真实构型是关闭前置，不是所有增量施工的前置；输入与自身任务到位后先预查支持域，再复用同一入口。接口未满足的新能力仅增量扩既有入口，不造平行工具。

当前入口及源样本切片证据见 `acceptance/records/2026-10-20-robot-body-precheck-entry.md`、`acceptance/records/2026-10-20-robot-body-precheck-plan-fixes.md`、`acceptance/records/2026-10-20-robot-body-precheck-source-geometry.md`。复读命令及失败类别在记录，不在指南复制数值或通过数。

## 最小增量探测

1. **绑定输入**：明确源／候选 URDF、网格、轴／限位、代码、命名与地面／根姿态。摘要复用 `rl_exp/tools/runrecord/binding.py`。先核已有报告身份与覆盖，再决定哪些证据直接沿用；若需新输出，使用隔离的新目录，不覆盖历史产物。
2. **保留对照**：使用相同其余关节、根姿态及判定方法，对比新轴零位与旧机构；无几何或方法变化的尺寸与中立读数不无差别重测。
3. **只扩变化方向**：新增 twist 时，补其非零上下文中的肘膝／腕踝切片，明确 swing、abduct、根姿态和其它腿状态。前后肢分别取真实树，左右按实际镜像验证，不默认同号或同范围；只扫单轴零上下文会漏耦合变化。
4. **分开记录判定**：实体相交、指定间隙不足、反曲、掌面有向状态、最低碰撞顶点地面间隙分别报告。地面检查需显式摆位并变换实际网格，不能以掌中心位置代替；倾掌本身不是失败，滚动与材料接触滑移不能仅由静态几何判定。
5. **保存反例与覆盖**：保留完整具名姿态、固定上下文、网格对、地面、采样间隔与转折括号。报告说明未采区域、共用 FK 假设及过滤范围；离散通过不等于连续轨迹、全维安全域或最终关节限位。
6. **再提出动作输入**：由上述读数提出步长、抬脚候选及依据，交相位目标决策；不继承旧周期、占位限速或 PD。周期与承重能力须另由动态标定支撑。

输入不被方法支持、身份不明或具名角色错配时停止该读点，不换旧资产、旧名表或扩大过滤掩盖问题。新增拒错／行为修复必须用真实失败对照验证；单纯声明一致不能作为行为能力证明。

## 局部转折复读

已有静态切片出现相邻分离／相交样点时，使用 `palm_spatial_probe.py --refine_slices`，显式提供 `--build_report`、`--source_report`、`--angle_resolution` 和全新 `--output_dir`。当前入口定位右后腿机身／踝掌目标对；复用源网格的相邻异态边，不替代通用全域扫描。校验源候选、固定姿态与过滤集合，重新检查完整碰撞对；仅当前 probe 新增模式的摘要允许与源不同，其余依赖变化须先解释，不能悄悄复用旧判词。

二分只收缩两端异态括号；同态边内部窄带未覆盖，非单调边可能存在其它转折。`--angle_resolution` 只约束角宽，不代表机械精度、安全余量或已批准关节限位。报告保留来源角网格、两端完整姿态、网格对及地面读数，结果仍归验收记录。

## 局部路径复读

使用 `palm_spatial_probe.py --local_path --build_report <绑定输入> --output_dir <新隔离目录>` 探测两腿中立附近的闭合路径；数值口径与预算集中于模式配置并写入报告。复用完整五轴、网格最低特征、全体碰撞对和源身份，不调用历史平掌 `solve`。任务达标即停，实际残差调用包含有限差分；接地后摆将端点参考 XY／最低高度与关节线性插值中点最低高度联合求解，仍共用原每点尝试及残差调用预算，不另开中点求解。停止判据核全部任务残差，不包含末尾逐关节正则；端点与中点仍独立复核全部几何条件。中点偏离接触约束是路径表示的缺口，不能自动归因于机构不可达；失败保留阶段，不放宽容差、跳过中点或声称整条腿能力失败。端点和中点接地不证明它们之间全程接地，特征切换附近仍可能漏过窄离地／穿透带。

`completed_local_loop` 仅指该探索路径的离散点／中点及完整关节分支回归检查，不代表自然步态、连续域、世界无滑移、时间映射或动力学合格。路径失败时先核任务残差、预算停止、几何和分支插值，复用已采姿态定位责任层。

## 已采路径后处理

`local_path_view.py --source_report <local_path report.json> --output_dir <新隔离目录>` 独立读取 `budgeted_local_path` 报告，复用绑定的 URDF、网格和 FK，不导入求解器或调用碰撞扫描。数值分析只消费原端点，按实际非均匀 s 计算逐段 dq/ds、内部与周期斜率跳变；渲染只消费原接受端点和关节线性中点，不平滑、不新增姿态、不从播放时长推导速度。

输入须保留 build、候选文件与采集 FK 摘要，完整具名关节对应实际树。每帧掌最低标记、法向与参考点需对齐绑定 FK；这些是显示一致性，不是重新验收接触或碰撞。失败报告只画接受前缀，不把拒绝端点或 GIF 重播接缝当闭合段。

输出独立 `analysis.json`、逐腿轨迹／斜率 PNG 与侧／俯视 GIF，保留源报告和后处理／工件身份。`_path_stats` 可单独复用数组与相位的计算，不绑定腿数、关节数或命名；当前 CLI 只支持已声明的局部报告格式，不自动兼容其它历史 CSV 或运行时报告。斜率单位是 rad/无量纲路径参数，不是 rad/s；阈值、时间映射和段内接地加密须另定，不能从动画生成成功推导路径通过。

## 已采路径四分点检查

`local_path_check.py --source_report <local_path report.json> --output_dir <新隔离目录>` 对原接受段的关节线性插值增加 1/4、3/4 几何读点。复用 `local_path_view` 的报告／身份校验及原 `_static_prepare`、完整五轴 FK、网格地面读点、碰撞对和 `_local_failures`；不调用求解器、不改采集轨迹或显示入口。当前预算每腿最多 64 个新姿态，首个失败立即停止该腿，不自动递归加密。

源报告的候选、采集代码、根姿态与碰撞集合须一致；原端点／中点判词作为源证据保留，不计作本轮新复核。四分点沿实际相位核接地、全体实体穿地、反面掌、反曲、非批准实体碰撞及限位；落掌按原采样顺序核最低高度不增加。新增采样不能借机加强成固定掌面或虚构材料点无滑移目标。`full_source_loop_quarters_pass` 只指完整源路径的获准四分点全部通过，不指连续域、光滑接缝或动力学合格。

## 已采路径另两腿镜像检查

`local_path_check.py --mirror --source_report <两腿完整 local_path report.json> --output_dir <新隔离目录>` 不求解，从真实链轴的轴向量反射推导逐关节符号，并核镜像后的限位区间。只映射实际角色对应的完整五轴，不默认同号，不复制源腿的几何判词；其余关节仍零。

目标腿重新检查中立及每段 1/4、1/2、3/4、终点，输入身份和全机地面／碰撞口径与原四分点入口相同。每腿限预算、首次几何失败即停；目标最低高度、离地及前后行程、落掌顺序、全机地面、实体相交、掌面、反曲、限位与完整分支闭合独立读回。它只验证两条单腿镜像路径，不验证四肢组合、接缝平滑、世界无滑移、时间映射或承重；数值结果与本轮获准预算只取实例验收记录。

## 已采路径四肢组合检查

`local_path_check.py --combined --source_report <两腿完整 local_path report.json> --output_dir <新隔离目录>` 将原闭合路径按同相对角与另组半周期错相组合，根机身固定。复用镜像轴／限位校验及关节线性插值，每个完整组合姿态只计算一次全机碰撞与地面，再检查四掌各自相位、方向、离地、落掌和完整分支闭合。逐姿态保存全机几何、完整关节及四掌读点，不以单腿历史判词代替组合检查。

当前 CLI 只接受原已声明的两腿完整均匀网格；组合身份、预算和实例相位由验收记录绑定。记录实际几何接地腿集合，允许观察到所有掌均离地，不把检查完成或组合闭合称承重步态通过。无物理时间、根推进、无滑移、相位重设计或接缝平滑；不能从碰撞通过推导持续支持能力。

## 支持相位与保几何节点重参数化

`local_path_check.py --combined --support_schedule` 使用实例批准的支持占比，保留源关节直线段及全部节点；每段用五次缓入缓出遍历，在原折点和周期接缝使无量纲参数的一、二阶导数归零。它改变各腿在组合周期中的相位映射，故重新检查组合碰撞、地面及采样几何接地腿数；采样包括两组全部原节点和合并节点区间的中点，限预算、失败即停，不递归加密。

该简化会在每个原节点停速，不是几何圆滑、自然步态或已批准物理速度；周期参数不带秒数。原 q(s) 的折点与历史判词保持不变，新 dq/dc、d²q/dc² 不能冒认 rad/s 或 rad/s²。最低点数值接地只证明获准采样下的几何接触，不能替代力、稳定性、世界无滑移或连续域证明。实例占比、复验结果与未完动作唯一取验收记录。
