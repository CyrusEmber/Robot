| run | 做法 | 判定 |

着地闸（2026-09-11 补，用户提出「零命令 10s 脚不在地上」后加）：tilt/drift 之外必须报
**几只脚承重**——只看 tilt 会漏掉「站得住但脚悬空」。口径：

- 着地 = 该脚接触传感器法向力 > 1 N（`FOOT_CONTACT_N`）
- 辅助几何口径 = 脚 body 原点世界 z；flat 列地面 z=0，**落地基线 ≈0.07–0.08 m**
  （脚 body 原点本身的常量偏置，不是离地间隙）→ 判「悬空」看 z 显著高于同 run 的
  贴地脚，不看绝对值
- 判据：零动作/零命令稳定段应四脚着地（非四脚着地占比 ≈ 0，仅落地瞬态允许例外）

条件：训练同资产同 PD，DR 全关（nominal），固定出生姿态。

## Phase 2 平地直行（9 runs）

- 50Hz 记录：base/胸段/头颈倾角与离地高度；各 link 接触力；四脚接触状态与

  「先低头撑地」还是「先失稳后找支撑」

## Phase 3 单级台阶（≤ 24 runs，早停）

### 诊断表回填

| 观察 | 结论 |
|---|---|
| 默认关节目标也站不稳 | **未见**（6.1° 稳站，四脚着地） |
| 头颈承重、脚悬空，belly≈0 且 tracking 高 | **脚悬空部分复现**（零命令全程非四脚着地，右后脚恒 0 力）；但头颈承重 0、非"找支撑"型异常——是姿态偏好，非接触覆盖/奖励漏洞 |
| **零命令下脚不在地上（用户提出）** | **复现**：全程仅 2–3 脚承重，`rl_foot` 悬空 6–15 cm；tilt 与 drift 判据看不出来（着地闸已补进 Phase 1，见上） |
| base 持续倒置但 eval 不报 fall | 未复现；**变体已复现**——支撑退化（三脚站）同样躲过 eval 几何判据 |
| 平地正常，超过某级高度才卡住 | **未见**（≤20cm 全过，无能力边界） |
| 搭腹能通过但受明显惩罚 | **未见**（无任何搭腹） |

**结论：在 0.3–1.0 m/s、nominal DR 关、单级 ≤20cm 台阶条件下，运动中的担忧异常
（头颈承重、搭腹越障）完全不出现；但静止条件（零命令）下策略退化为 2–3 脚支撑，
右后脚全程悬空——这是本轮新增的唯一确凿异常，且它躲在原 tilt 判据的盲区里。**
剩余未覆盖区：更高速度、robust 级扰动（4 m/s 踢 + DR——即 robust eval 里穿透异常
的那个 regime）、连续窄踏面（0.7m 金字塔楼梯，eval 已知 completion 0.83）。
若需继续，下一步应测踢后恢复行为（悬空脚在扰动下是否会代偿）而非再扫台阶高度。

### 实现备注（坑与修法，防再踩）

1. `reset_base` 基类默认 yaw ±π 随机——体坐标命令导致各 env 往随机方向走，
   台阶列全部失真；诊断脚本钉 `pose_range["yaw"]=(0,0)`。
2. 单级台阶条件：`platform_width` 必须**严格大于** `size−2*border`；恰好相等
   时 floor 除法给 num_steps=1 = 两级台阶（离线 trimesh 校验抓出）。
3. rsl_rl wrapper 的 `reset()` 返回 `(obs, extras)` 元组，策略吃裸 obs。
4. 接触力/体重需先走若干物理步再读（reset 后首读为 0）。
5. 脚着地要同时存**接触力**（判据）与**脚 body z**（几何复核）：只存 `feet_down`
   整数计数就没法回答"哪只脚悬空"，逐脚 `fz_feet`/`foot_z` 必须落进 json
   （2026-09-11 补，p1c 存档因缺逐脚时序只能重跑）。
6. 脚 body 原点在贴地时有 ~0.07 m 常量偏置——"悬空"要跟同 run 的贴地脚比，
   不能拿绝对 z 比 0。
