# baseline 线（平地行走基线）

> 本文件 = 线的**路线与意图**（将来时）；可行事实归 FAMILY.md，本轮配方归 `vN/PLAN.md`。
> 结果归 `vN/NOTES.md`。开版流程继承 `.codemaker/rules/versioning.mdc` §A。

## 这条线为什么存在

既有粗糙地形线的变量太多且互相耦合（地形 + 两套课程 + c_k + DR + 特权观测 + 16 项奖励
槽位 + 多代继承），任何一次失败都难以归因。本线把配方清到**只剩一个问题**：这副机器人
能否学会在平地以固定低速持续行走。它**不是**既有线的新版本，也不与既有线共享配方代码
（`base.json` 为 `null`）；共享的是资产、参数格式、评测台与闸门。

## 轮次路线（每轮只加一个变量，加完先跑通再进下一轮）

| 轮次 | 唯一新增变量 | 前置 |
|---|---|---|
| v1（当前） | — （平地 + 固定 0.5 m/s + 零课程 + 零 DR） | 无 |
| v2 | 命令档位：固定点 → 少量档位（如 0.3/0.6/0.9 m/s，命令采样） | v1 达标 |
| v3 | 域随机化：**按受控顺序**加回（质量 → 摩擦 → PD → 关节摩擦/armature） | v2 达标 |
| v4 | 外力与推力：先常值外力，后 interval 推力（这两项在既有线里**不受 c_k 门控**，独立于课程） | v3 达标 |
| v5 | 转向：开放 `ang_vel_z` / `heading_command` | v4 达标 |
| v6+ | 地形（平面 → 轻起伏 → 粗糙）、课程（含阶段速度）、观测扩展（脚环/特权）——**每个都是一版** | 逐版达标 |

硬纪律：

- **不跳轮次、不合并变量**；一版只改一处，否则回到"无法归因"。
- 观测/网络的结构变化单独成版（观测切换不是"一行 A/B"，见 `v1/PLAN.md` 前提校正 1）。
- 每轮判决要么"达标进下一轮"，要么"归因后改一版重跑"，不允许"再观察观察"式的悬置。

## 与其它线的边界

- **资产与平台接口共享**：usda、URDF、PD、动作拆分、`dt`/decimation。改它们属平台换代，
  不是本线的变量。
- **配方代码不共享**：本线只依赖框架基类与框架 mdp，加上自己的 `baseline_mdp.py`
（两个奖励核的数学/坐标系/传感器契约由 `test_baseline_mdp.py` 钉住）。配方元素在
  `baseline_recipe.py`；注册入口按需加载，构造 baseline 不 import main 的 cfg 或 mdp。
  共享 `recipe_factory.py`、参数加载器与 PLAY 工具；全仓闸门仍可同时检查两条线。
- **评测台共享**：`ablation_harness` 与 `rl_exp/tools/diagnose/*` 是跨线公共设施。

## 何时该收线

若在 v1 的平面、零 DR、零课程条件下，多 seed 都无法得到持续行走（跟踪与位移不达标而
非"站着不动刷分"），只能得出**本配方在已记录的训练预算下未学成**，不能据此证明资产的
能力上限。多 seed 不能排除所有 seed 共用的奖励、探索或优化障碍。先检查实现、每项奖励
量级与学习曲线，再用单变量配方对照或独立动力学证据区分优化问题与资产限制；在归因前
暂停增加任务难度。零动作站立与启动探针通过只排除被测故障，不排除所有实现缺陷。
