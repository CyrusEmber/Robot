# lizard2 设计计划：main/v3

> 更新：2026-10-10。修订：v3.4（用户拍板启动训练并冻结；预算仍为 6000）。
> 本版采用本轮候选机体，唯一母本为 v2；自检已于 2026-10-09 完成，2026-10-10 冻结（tag `lizard2-main-v3`）并启动训练。
> 家族 PLAN 仅作入口，设计正文唯一在本文件。

## 目的与假设

将默认腿形、左右对称、骨段比例与运动轴整理成一套可执行的巨蜥风格机体，再配套初始关节角、限位和训练方案。第一阶段目标是工程可用，不以获得完整动物动作数据为前置，也不声称精确复现科莫多运动。

假设：修正静止几何和对应转轴，能让指定腿形成为自然可用的起点；训练仍需明确姿态目标，几何正确不保证策略自动采用这种走法。若静态合格而完整周期失败，应记录失败原因，区分结构、目标与求解问题。

## 范围与候选选择

| 项目 | 草案安排 | 定案依据 |
|---|---|---|
| 左右对称 | 同对前腿、同对后腿分别镜像；关节点、网格和轴向一起核对 | Blender 执行单及导出镜像检查 |
| 骨段长度 | 第一候选保留主侧骨长，另一侧镜像；需要改变比例时另留候选比较 | 腿形、体高、接地、碰撞与执行器需求 |
| 默认姿态 | 按用户指定的前后肢折叠方向设计静止几何；方向表唯一归 Blender 执行单 | 用户检查候选预览，随后核验导出与承重 |
| 运动轴 | 匹配新的静止腿平面，不能沿用与几何脱节的世界轴 | 单关节正负运动、骨段与足端 FK |
| 股骨长轴旋转 | 保留为结构备选，不由静态腿形或论文重要性单独决定增加 | 当前链的完整动作缺口及同目标候选比较 |
| 动作接口 | 用户拍板：取消踝部 `kfe` / `foot` 的策略动作通道，保留可动关节与 PD；具体语义唯一归 Blender 执行单“动作通道决定” | 通道集合、默认目标与运行时驱动检查 |
| 限位与初始角 | 按新零位、轴向及所需动作确定；不把动物常用活动范围当硬限位 | 碰撞边界、连续动作、承重与执行器检查 |
| 训练 | 沿用现有平地训练机制作为起点，评估少量明确姿态要求 | 学到的腿形、接触、稳定性与速度跟踪 |

用户拍板：2026-10-08，采用 `rl_exp/lizard2_candidate/` 中的本轮 URDF/网格与原候选 USD（同目录归档，与原转换产物逐字节一致）。保持全部可动关节、全部 PD 与默认零目标；策略只命令 hip/haa/hfe 与 spine。奖励、命令、时序、终止、无 DR/课程沿用 v2，不增加姿态奖励或调整限位。完整机器差异唯一归 [diff.json](diff.json)。

用户拍板：2026-10-09，本版**预算声明为 6000 迭代**（v3.3 修订；v2 的 14000 不再沿用）。理由：采用机体未训练、其限位/踝向/碰撞面仍在 `work/active/joint-limit-shape-and-range-pass.md` 挂账，所以这一 run 是"读新机体的短窗"，不是训练候选；它的任何读数只能说"截至 6000 步"，不能称收敛或修复。改动面 = `agent.max_iterations` 一个叶子 × 两个任务，配方锁重锚与证据见 `acceptance/records/2026-10-09-lizard2-v3-budget-and-calibration.md`。

## 推进顺序与责任

1. 采用本轮用户批准的导出，来源唯一归 `acceptance/records/2026-10-08-lizard2-blender-body-candidate.md`。
2. 同次退休加载旧机体的 v1/v2，删除旧资产锁，保留历史 yaml、注册与文档；不刷新旧锁、不改旧配方。
3. 运行 v3 正式 train/play 的构建、obs 实测、PD/默认目标与最小运行自检；不以 `--drop-joints` 模拟替代。
4. 限位、完整动作周期、mesh 碰撞与旧机体开自碰撞对照另由 `work/active/joint-limit-shape-and-range-pass.md` 承接，本轮不声称验收。后续需求与当前状态见 `acceptance/records/2026-10-09-lizard2-limit-requirement-and-status-sync.md`，技术判据消费评审合同 R4；本次仅补记录指针，不改本版资产或配方。
5. 后续训练必须另经用户确认；启动方案使用 `Lizard2-Flat-v3` 与独立日志目录（`lizard2_v3`），预算 6000（v3.3），先预检再冻结。训练已于 v3.4 用户拍板后启动（预检、干净树与启动闸门均先过）。

## 验收与开训条件

| 观察结果 | 下一步 |
|---|---|
| 候选腿形符合用户要求，且镜像、接地与绑定可复查 | 进入导出与动作验证 |
| Blender 外形正确，但导出后轴向、默认角或网格位置不一致 | 修导出/配置，不能进入训练 |
| 取消动作通道后，对应关节仍保留驱动且目标等于版本默认角；动作与观测布局匹配 | 进入运行时接触和承重验证；恒定目标不等于实际关节被锁死或脚掌始终水平 |
| 采样姿态可达，但中间路径、周期闭合、碰撞或承重失败 | 保留失败证据，修目标或结构；不能只加密采样后宣布通过 |
| 新机体与动作可执行，配方及验收口径明确，版本与资产检查完成 | 建立训练候选并冻结 |
| 训练能走但腿形偏离目标，或以滑移/非足承重换取前进 | 不算目标达成；回查姿态要求及任务奖励 |

验收工具与方法沿用 `acceptance/records/2026-10-08-lizard2-joint-design-review-contract.md`；已有单腿探索只作方法与问题来源，不能直接当新骨架验收结果。新机体与旧模型同时变化时，跨版本差异只能说明方案整体表现，不能单独归因于某个奖励或自由度。
