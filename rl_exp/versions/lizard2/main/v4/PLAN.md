# lizard2 main/v4：正式 palm 位置策略配置

> 修订：v4。母本为已训 main/v3；本版从头初始化，不续训旧 checkpoint。配置冻结锚点为 `lizard2-main-v4`，是否已发布以实际 Git tag 为准；本轮不启动训练。

## 目的与假设

将已独立核验的 palm 草案落实到正式注册任务与稳定资产，开放全部实际位置动作，让 RL 学习平衡、卸载、移重及躯尾协调。默认驱动继承当前受载证据；小幅精度和有限工况不外推全姿态保证。执行职责见 [当前训练计划](../../../../../work/active/lizard2-family-landing.md)。

## 差异与依据

完整差异唯一归 [diff.json](diff.json)，母本边见 [base.json](base.json)。本版采用同字节 USD/URDF/OBJ、新关节名与实际动作集合，配置 SSOT 为 [main_params.yaml](main_params.yaml)。正式落点、源制品身份、静态对照和运行证据归 [配置验收记录](../../../../../acceptance/records/2026-10-23-lizard2-v4-configuration.md)。

采用 `lizard2_palm_spatial`，旧机体 main/v3 同次退休，历史参数/PLAN/NOTES 保留，不刷新旧资产锁。新元素 `lizard2_palm_interface` 落实动作 clip/order、运行时 caps、出生与 reset、接触子步采样及 TGS/false；既有元素和旧版本语义保持。

## 关键假设 → 最小探测 → 停止条件

| 假设 | 最小探测与依据 | 失败处理 |
|---|---|---|
| 正式落点与已审草案只有身份/路径及等价表示差别 | 对稳定资产逐字节摘要、正式构造器与草案快照逐字段对照；命令入口 `test_lizard2_v4.py`，结果归配置记录 | 额外物理、驱动、动作或奖励变化停接入，回实际责任层修复 |
| 正式工具按明确命名消费实际机体 | 不带 target_config 运行正式任务，核动作、四腕踝和真实关节顺序；错误命名负例拒绝 | 错列、漏轴或命名回退停接入，不修改旧版本含义 |
| 动作权限、观测与采样保持已审接口 | 复用隔离运行及其审核，补实际注册构建、102 维与新资产顺序；需重验的落点变化交 D | 声明一致不代行为通过，真实缓存/reset/漏采缺陷须修复 |

不增加触边、限矩、对称精度复测或手工步态；三类动态接触标定不作首轮开训前置。新增滑移/滚动/承重分类用于奖励、终止或合格判定前仍须对应验证。

## 配置边界与验收

- 每腿五角色及胸颈尾全可访问，采用显式顺序的位置参考；速度目标恒零，无差分前馈、额外动作滤波或手工控制器。
- 逐轴 scale 与硬限位 clip 按已审接口方案落入 YAML；默认 q/dq 零，出生四元数为本栈 xyzw，根自由、重力/自碰撞开启。实际驱动及限制继承具名受载输入，胸俯仰上限的显式覆盖保留。
- 七项本体观测、既有奖励和终止、速度命令范围、PPO 超参数、无 DR/无课程沿母本；接触每物理子步更新并保存控制窗历史。完整/子集/自动 reset 的既有证据按同身份和等价配置复用，新增终止或地形组合不冒称已验。
- 新任务、参数、golden、观测布局/运行顺序、资产身份与差异声明可复读；原读数、通过数与完整结论只归配置记录。

## 启动方案

任务为 `Lizard2-Flat-v4` / `Lizard2-Flat-Play-v4`，runner 为 `Lizard2V4PPORunnerCfg`；独立日志目录 `lizard2_v4`。首轮预算按用户已批从头初始化的 6000 迭代，无 resume。保留正式训练默认并行环境数；实际启动工况、环境数、seed 和命令随 run 绑定，不因本版配置存在假称已训。

启动前执行 `python -B rl_exp/tools/launch_recipe.py --task Lizard2-Flat-v4 --max_iterations 6000 --seed 42 --record rl_exp/out/lizard2_v4_launch_plan.json`；不加 `--launch` 只核启动身份和生命周期，不启动训练。核版本锚点、工作树、真实输入，并完成同配置集成和必要预检后，实际训练才加 `--launch`。本轮仅落实配置。完整动态协议不阻塞该流程；已校准报告项与待验策略目标分别记录，新增判据使用前固定口径及用户确认阈值。
