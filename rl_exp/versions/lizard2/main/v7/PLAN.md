# lizard2 main/v7：固定圆足与26轴位置策略

> 修订：v7.1。母本 main/v6.1（目录句柄 `v6`）；用户拍板：2026-11-03 正式接入 v7，同步退休旧机体 v4–v6，并批准本轮提交、冻结为 `lizard2-main-v7` 及同步远端；不启动训练。

## 目的与假设

采用已检查的 export04 固定圆足及收窄后的双肘限位，让强化学习直接学习支撑、移动与躯尾协调；不要求手工两足承重或步态先成功。圆足没有相对小腿的活动轴；当前双轴候选删八轴得到本机体，母本训练配方则从单轴掌足删四轴。两种比较基线不能混用。

球足尺寸、质量及实心球惯量沿用隔离诊断假设，不代表实物材料设计批准或性能优化。保留母本腿/躯干 PD、动作 scale、奖励、终止、命令、无课程/无 DR 与 PPO；不凭形状变化重调增益。新机体与动作维度不兼容旧 checkpoint，不默认加载旧权重。

## 差异清单

母本唯一取 [base.json](base.json)，配置路径与逐项理由唯一取 [diff.json](diff.json)。正式资产为 `rl_exp/lizard2_round_feet/`，来源、字节身份、参数来源与边界见 [接入记录](../../../../../acceptance/records/2026-11-03-lizard2-v7-round-feet.md)。旧机体冻结版本退出新训、续训与当前树复现承诺；原参数、任务身份、记录与标签保留。

## 验收

- TRAIN/PLAY 身份独立、固定足无动作轴；腿与躯干动作、初始状态及驱动集合覆盖全部活动轴，无遗留腕踝活动配置。
- 正式 USD/URDF/网格为 export04 有效修正制品的原字节，完整依赖可追溯；未修正 USD 与历史失败现场不覆盖。
- 双肘动作目标边界匹配收窄限位，未批准的参数不变；旧版参数与已推标签不改写。v4–v6 生命周期退休与资产采用同轮落地，不重锁旧版。
- 实际关节序、非零观测、动作后端及 reset/首步接口具名核验后方可交训练；缺证保持未验，不以离线全绿替代运行时结果。
- 训练后固定 checkpoint、命令窗口并录制多视角策略视频，检查存活、速度跟随、支撑/摆动、躯尾协调与转向。性能阈值未定不判通过，总奖励不替代步态证据。

## 启动方案

任务 `Lizard2-Flat-v7` / `Lizard2-Flat-Play-v7`；runner `Lizard2V7PPORunnerCfg`；日志身份 `lizard2_v7`。本轮冻结已审配置，标签 `lizard2-main-v7`；不将继承的runner迭代上限视为新训练授权，不自动启动PPO。接口与golden证据分别取 [接口记录](../../../../../acceptance/records/2026-11-03-lizard2-v7-interface.md) 和 [基线记录](../../../../../acceptance/records/2026-11-03-lizard2-v7-golden-rebaseline.md)，冻结实际执行取 [冻结记录](../../../../../acceptance/records/2026-11-03-lizard2-v7-freeze.md)。
