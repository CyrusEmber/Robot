# lizard2 设计计划：main/v3 草案

> 更新：2026-10-08。修订：v3.1（文档提案）。
> 本文是 v3 的当前设计草案；正式 `main/v3/` 配方目录、任务注册、冻结与训练尚未建立。
> 新机体采用前，把本草案迁入正式版本的 `PLAN.md`，本文件收回为家族路线入口，保持方案只有一份正文。

## 目的与假设

将默认腿形、左右对称、骨段比例与运动轴整理成一套可执行的巨蜥风格机体，再配套初始关节角、限位和训练方案。第一阶段目标是工程可用，不以获得完整动物动作数据为前置，也不声称精确复现科莫多运动。

假设：修正静止几何和对应转轴，能让指定腿形成为自然可用的起点；训练仍需明确姿态目标，几何正确不保证策略自动采用这种走法。若静态合格而完整周期失败，应记录失败原因，区分结构、目标与求解问题。

## 范围与候选选择

| 项目 | 草案安排 | 定案依据 |
|---|---|---|
| 左右对称 | 同对前腿、同对后腿分别镜像；关节点、网格和轴向一起核对 | Blender 执行单及导出镜像检查 |
| 骨段长度 | 第一候选保留主侧骨长，另一侧镜像；需要改变比例时另留候选比较 | 腿形、体高、接地、碰撞与执行器需求 |
| 默认姿态 | 按用户指定的前后肢折叠方向设计静止几何；方向表唯一归 Blender 执行单 | 用户检查候选预览，随后核验导出与承重 |
| 运动轴 | 匹配新的静止腿平面，不能沿用与几何脱节的世界轴 | 单关节正负运动、骨段与足端 FK |
| 股骨长轴旋转 | 保留为结构备选，不由静态腿形或论文重要性单独决定增加 | 当前链的完整动作缺口及同目标候选比较 |
| 动作接口 | 用户拍板：取消踝部 `kfe` / `foot` 的策略动作通道，保留可动关节与 PD；具体语义唯一归 Blender 执行单“动作通道决定” | 通道集合、默认目标与运行时驱动检查 |
| 限位与初始角 | 按新零位、轴向及所需动作确定；不把动物常用活动范围当硬限位 | 碰撞边界、连续动作、承重与执行器检查 |
| 训练 | 沿用现有平地训练机制作为起点，评估少量明确姿态要求 | 学到的腿形、接触、稳定性与速度跟踪 |

拟以 v2 冻结配方为训练起点；正式建版时在 `base.json` 确认唯一母本。踝部策略动作通道按本轮用户决定处理；具体奖励项、命令速度带、周期与预算仍未定案。完整机器差异在正式建版后由 `diff.json` 承载；本草案不冒充可执行配置。

## 推进顺序与责任

1. **用户在 Blender 制作候选。** 操作与结果回填唯一归 `acceptance/records/2026-10-08-lizard2-blender-body-candidate.md`；在办入口为 `work/active/leg-chain-symmetry-convention.md`。
2. **Codex 核对候选与隔离导出。** 比较静止关节中心、骨长、网格、实际脚底与运动轴；导出到候选路径，先不采用到正式家族资产。
3. **Codex 验证简单动作与限位。** 从默认站姿推进单腿支撑—离地—回收—再落脚，检查实际接触、碰撞、时间连续性和承重，再协调四腿；结果归 acceptance 记录。几何、限位与结构决策由 `work/active/joint-limit-shape-and-range-pass.md` 承接。
4. **明确配方后建立正式 v3。** 配方、动作接口、注册与评测交付由 `work/active/lizard2-family-landing.md` 承接。正式采用新机体的生命周期操作遵循 `.codemaker/rules/versioning.mdc` §A；不靠刷新旧资产锁消除漂移。
5. **预检、冻结，再训练。** 运行参数、默认角和资产确认一致后再填可执行启动命令；目前不提供指向尚未注册任务的开训命令。

## 验收与开训条件

| 观察结果 | 下一步 |
|---|---|
| 候选腿形符合用户要求，且镜像、接地与绑定可复查 | 进入导出与动作验证 |
| Blender 外形正确，但导出后轴向、默认角或网格位置不一致 | 修导出/配置，不能进入训练 |
| 取消动作通道后，对应关节仍保留驱动且目标等于版本默认角；动作与观测布局匹配 | 进入运行时接触和承重验证；恒定目标不等于实际关节被锁死或脚掌始终水平 |
| 采样姿态可达，但中间路径、周期闭合、碰撞或承重失败 | 保留失败证据，修目标或结构；不能只加密采样后宣布通过 |
| 新机体与动作可执行，配方及验收口径明确，版本与资产检查完成 | 建立训练候选并冻结 |
| 训练能走但腿形偏离目标，或以滑移/非足承重换取前进 | 不算目标达成；回查姿态要求及任务奖励 |

验收工具与方法沿用 `acceptance/records/2026-10-08-lizard2-joint-design-review-contract.md`；已有单腿探索只作方法与问题来源，不能直接当新骨架验收结果。新机体与旧模型同时变化时，跨版本差异只能说明方案整体表现，不能单独归因于某个奖励或自由度。

## 结果与记录安排

实际测量和结论进入 `acceptance/records/`，本方案只引用。正式建版时建立 `NOTES.md`，包含设计引用、本版重点变化、实际执行与偏离、结果回填、结论；填 run 路径、复读命令及报告路径，不复制探索数值或旧版结果。当前没有本版训练 run 或仿真验收判定。

## 明确留到后续的内容

完整动物量测、精确科莫多周期与完整模仿学习系统不作为本轮前置。骨长比例、增轴、姿态容差与训练奖励有未决项时，先保留工程候选标签，不用未经验证的角度补齐所谓生物标准。
