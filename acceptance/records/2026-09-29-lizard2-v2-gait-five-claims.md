# 五条目测的核对：大腿确实最少，前对同相，躯干 yaw 只在快档动（2026-09-29）

## 适用范围

- 被评对象：`logs/rsl_rl/lizard2_v2/2026-09-28_17-02-42/model_9999.pt`（v2 配方：脚板无动作通道）。
- 核对的输入：探针 `gait_probe.py` 三档 0.5 / 1.5 / 2.8 m/s、20 s 与 8 s 两份报告（机器本地
  `out/gait_probe/gait_v2_chain.json` / `gait_v2_spine.json`），以及评测记录
  `results/lizard2_flat_v4/v2/…_joints30/eval.json`（256 envs、seed 123、20 s，命令 0–3 混档）
  与其帧文件（机器本地）。
- **不覆盖**：视频观感里无法落到读数上的部分（"看着别扭"）；接触力的方向；力矩；以及"什么算像蜥蜴"（无参照群体）。

## 验收条件

1. 每条目测都要落到**已有读数**上；落不到就**点名缺哪一列**，不许拿近似量顶替。
2. 统计量必须写清：`5–95%`（持续摆动）与 `peak-to-peak`（含偶发尖峰）**并列给出**，两者在本机体上差 4–6 倍。
3. 相位必须**折回周期**再读（同一信号在周期外有多个等价最大值，不折回来等于没读）。
4. 相符与不相符都写；**不给因果**，机制只以"读数入口"的形式提出。
5. 承重相关量只在**承重帧**上读（空中的行程与承重期的行程是两个断言）。

1. **`haa`（大腿抬落）是整条链里最小的一列**：0.5–27.4°（5–95%），而后侧两条腿（rl 10.7、rr **4.6**）几乎不动大腿。
2. **动得最多的是膝与小腿**（`kfe` 到 54.1°、`hfe` 到 52.7°）⇒ 腿靠**折膝+折踝**伸缩，而不是靠大腿摆动。
   左前腿是最纯的一例：承重期 `hip` 只有 **3.2°** 而 `hfe`/`kfe` 各 53–54°。
3. **这两条把 ② 与 ④ 接上**（机制假设，非结论，且范围限于**这些承重姿态**）：大腿抬不起来 + 小腿在承重期摆 10–54° ⇒ 板跟着摆，
   而脚板关节自己的行程只有 ±28.6°、实际只动到 13° ⇒ **在这些姿态下**板立边是这条链的后果，不是某个关节的故障。
   要判它，需要的是"小腿在承重期的角度摆动"这一项的**时间序列对板倾角**——两者在读数上同源（板≈小腿，误差 1.45°），
   所以本记录只给出入口，不给因果。
4. **另一条独立发现**：`spine_leg_coupling` 在配对数从 120 涨到 200（腿关节 12→20，同一份记录）时由
   **0.7776 变成 0.8107** ⇒ 该项"对取最大"上限被实测证明：**它的值随池子大小变**。引用它时必须同时说明池子。

### ③ 判定

1. **五条里四条对、一条半对**：① 前对同相、② 大腿动得最少、③ 立边、④ 板—小腿角几乎不变
   （"怪"在整条小腿而不在这条夹角）都成立；⑤ 只在慢档成立。
2. **"像狗"的证据结构**（本记录只摆证据，不下结论）：支持的是**姿态与用法** —— 立边承重、
   大腿不抬、靠折膝踝推进、慢档也用跑的占空比、前对同相；**不支持**的是"步幅来源"——
   前后位移仍主要由髋（横扫黑）承担（相关 0.66–0.84）。两者可以同时为真：**横向扫髋 + 不抬大腿 + 折膝**。
3. **本轮改掉的不是配方**：只是让这些量从此**可读**（探针记全链、采集侧记全 30 关节）。

## 未覆盖边界

1. **单 checkpoint、单 seed、三个 env（探针）**：本记录是机制读数，不是分布。
2. **5–95% 与 p2p 并列，不能混用**：前者问"持续摆动"，后者含偶发尖峰；两者在本机体差 4–6 倍（同源教训见
   `2026-09-29-gait-shape-in-the-eval-flow.md` 的 ③）。
3. **相位是相关最大处**：周期用 lf 着地间隔的中位数估的；2.8 m/s 下后脚接触抖动（45 周期里 61 次着地）
   ⇒ 该档的后腿相位偏软。
4. **base yaw 是"朝向差"而不是纯摆动**：5–95% 里含慢漂，分不出摆动与转向。
5. **"大腿动得少"只对这条链成立**：`haa` 的行程小不等于它在力学上不重要（它承担的力矩没有测）。
6. **`spine_leg_coupling` 随池子变**（本记录实测），引用时必须带池子大小与上限。
7. **不含视频**：本记录不引用图像；视频是相机、不产读数，两者不互相代替。
