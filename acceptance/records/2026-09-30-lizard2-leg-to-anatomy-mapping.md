# lizard2 腿链 → 巨蜥解剖自由度：映射与结构差异（2026-09-30）

## 适用范围

把 `lizard2` 后肢的五关节链与巨蜥后肢做**功能类比**，并判定模型的结构表达限制。四腿 FK 自检不等于四腿解剖映射；前肢肩—肘—腕须另做。只做**轴级/骨段级**判读，尚未与目标动物的三维姿态序列对齐；候选限位定值归 `work/active/joint-limit-shape-and-range-pass.md`。已检索资料未获得可用的巨蜥被动 ROM 数值，不能据此填生物硬限位（见 `2026-09-29-varanid-joint-range-of-motion-evidence.md`）。

## 验收条件

- 每条结论必须能追到 ① 资产轴向（URDF/generator）② 本仓工具的可运行断言 ③ 已成立的读数记录；**功能推断**（"这个关节相当于什么肌肉动作"）与**几何事实**分开写。
- 表达不了的解剖动作合并记为**结构表达限制**（同源者不拆条），并写明"为什么限位/参数解决不了"。
- 同一量在不同工具下口径不同时必须标出（本记录就有一处：髋力臂）。
- 不把跨物种趋势（Clemente 2011/2013，≤8 kg）当成本资产的角度依据。

## 结果

### 链条与共位关系（事实）

腿链自根向端：`hip` → `haa` → `hfe` → `kfe` → `foot`（五条轴的轴向见下：`generate_urdf.py:50` 与 URDF 实测）。`hip` 与 `haa` **同原点**（`hip` 是后加的 meshless 微链，各 0.05 kg）。骨段：`haa→hfe` 之间是股骨，`hfe→kfe` 之间是胫骨，`kfe` 之后是脚板。

| 关节 | 零位轴（base 系） | URDF 限位 | 决定哪一段的姿态 |
|---|---|---|---|
| `hip` | (0, 0, 1) 竖直、腿根 | ±0.60 | 整链绕竖轴在水平面扫 |
| `haa` | (−1, 0, 0) 横、与 `hip` 共位 | ±0.60 | 股骨在体侧平面内抬/落 |
| `hfe` | (−1, 0, 0) | ±1.20 | 胫骨相对股骨（同平面） |
| `kfe` | (−1, 0, 0) | ±1.60 | 脚板相对胫骨（同平面） |
| `foot` | (0, 1, 0) | ±0.50 | 脚板绕横向轴滚转 |

### 解析身份：完整姿态与相对水平机体的倾角分开

按标准右手主动旋转约定，脚板 link 相对 base 的完整姿态为 `Rz(hip) · Rx(-σ) · Ry(foot)`，其中 **σ = haa + hfe + kfe**；负号来自三铰链的 −X 轴。FK 复算与符号勘误见 `2026-09-30-lizard2-joint-limit-plan-review.md`。

`hip` 只在相对机体 z 的法线倾角中消去，不从完整姿态中消去。机体水平时，该倾角也才等于世界系倾角；有 roll/pitch 时要乘机体姿态再读。按工具 `fold_tilt_cos`，若掌面自身下向单位法线为 `(nx, ny, nz)`，则 `cos(tilt) = ny sin(σ) + (nx sin(foot) - nz cos(foot)) cos(σ)`。只有理想法线 `(0,0,-1)` 下才简化成 `cos(σ) cos(foot)`，当前网格有偏移，不能称 foot 只有 cos 通道。

骨段级可分；三铰链对脚板**朝向**的作用通过 σ 合并，但其分配仍改变骨段与足端位置。完整姿态依赖 `hip/σ/foot`，相对水平机体的倾角依赖 `σ/foot` 与掌面法线。当前 `fold_tilt()` 的绝对值会折叠掌面正反方向，不能直接作“朝下且平放”验收；反例与工具前置见 review 记录及活跃方案。

### 映射（几何事实 + 功能推断分开写）

| 机器人 | 解剖对应（**推断**，依据轴向与骨段位置） | 表达性 |
|---|---|---|
| `hip` | 股骨**前引/后缩**（retraction/protraction，跨步） | 可调腿平面方位；不是唯一影响足端前后位置的轴，作用量随姿态变 |
| `haa` | 股骨**外展/内收** | ✔ 可表达，但只在体侧平面内 |
| `hfe` | 膝**屈伸** | ✔ 可表达（范围含 13.61° 反折，属**限位形状**问题，非表达性） |
| `kfe` | 踝**跖屈/背屈** | ✔ 可表达 |
| `foot` | 足端/脚板调整 | △ **部分**：只有一条局部转轴；不能独立控制所有足端朝向，不代表扩大此轴即可补偿任意倾斜 |

### 结构表达限制（限位解决不了，结构候选归活跃方案比较）

1. **远端链运动平面不能相对*机体*倾斜，只能改变方位角。**（原记的"缺股骨长轴旋转"与"平面 3R 机构"是**同一条**，已合并——静/动两种说法。）
   - 事实：`haa`/`hfe`/`kfe` 是**平行轴**，且随 `hip` 一起绕**机体 z 方向**旋转；`haa` 轴在机体坐标里恒为 `Rz(hip)·(−1,0,0)`，**z 分量恒为 0**（本次实测：`hip` 自 −0.60 至 +0.60，z 分量恒为 0.000e+00）⇒ 三个平行轴张成的运动平面**永远包含机体 z 方向**（**机体水平时**它才等于世界竖直——这是水平机体的口径，不是一般结论）。
   - 推论：这条腿的可动空间 = **平面方位角**（`hip`）+ **平面内三关节**（σ 的分配）+ **脚板滚转**（`foot`）。平面能转方位角，**不能转倾角**；动物的股骨长轴旋转买到的正是那个"倾角"。
   - 回归落点：不变式已进 `check_leg_reachability.py`（髋轴即机体 z 的字面断言 `:387`；扫遍髋行程、含端点，验证 `haa` 轴 = `Rz(hip)·(−1,0,0)` 且 `|z| < 1e-12`，`:390-395`）。连续行程的保证来自**轴向与变换关系**，离散扫描只是回归检查；**破坏测试**（髋轴扰为 `0 0.3 1`、`haa` 轴扰为 `-1 0 0.3`）两次都 exit 1，但**首闸是更早的既有断言**（倾角不变、铰链平行），所以这条是**后备闸**，不是首闸——写在这里以免下次误以为它守住了第一道。
   - 处置：**若**通过增加关节改变构型，按**当时**的 `versioning.mdc` §A 越级条款属**换家族**，不是任何 vN+1。"在髋插一条 y 轴"只是**构型示意**——能否真的实现股骨长轴旋转，还取决于**插入位置**与该轴**随哪段骨段**转，不能由"轴名是 y"推出来。
   - **2026-09-30 更新（本条原写"该提议未落地前按现行规则写，落地后此处的落点要跟着改"，此即那次回改）**：`body-swap-and-version-retire` 已落地并关闭——"构型变更必换家族"被"**采用新机体 ⇒ 依赖旧机体的冻结版本在同一次变更里退休**"取代。所以上面这条结构改动**不再自动换家族**，而是同一家族内的**机体换代**：新机体走新路径，旧机体上的冻结版本同变更退休（其资产锁随退休删除，且锁永不刷新）。规则落点 `versioning.mdc` 越级段；检查落点 `check_dr_parity.py` 的 body swap 一节（判据 = 活跃线 dev yaml 声明的 `usd_path`）。证据见 `acceptance/records/2026-09-30-body-swap-and-lock-freeze.md`。
   - 优先级（**工程判断，非文献结论**）：股骨长轴旋转优先于无巨蜥直接依据的关节平移，进入离线结构候选比较；不是已经批准增加关节。若目标要求腿平面相对机体倾斜，当前不变式可排除旧结构；是否采用新增轴，还须在同一目标下同时核对骨段方向、足端轨迹、连续性、碰撞与动力学。落点 `work/active/joint-limit-shape-and-range-pass.md`。
2. **三铰链在脚板朝向上通过 σ 合并**：这是串联运动学关系，不是关节被机械耦合，也不能单独证明需要组合限位。必须先定义不可接受姿态，再给违规组合和保守收窄的任务代价；本记录未完成该判定。

### 模型有效性边界（独立保留，**不列为本项待修缺陷**）

纯转动铰链**不表达旋转—平移耦合**：tegu 的 XROMM 证据显示关节存在该耦合（方法层面、非巨蜥数值），本资产全是固定转动铰链。它是**结论的适用边界**，不是待修缺陷。

**要复现的对象决定对平移的处理：**

| 要复现的对象 | 对平移的处理 |
|---|---|
| 巨蜥式支撑、摆腿、步幅和足端轨迹 | 先保留纯转动近似，验证目标动作**能否表达** |
| 骨段姿态、关节中心运动的精确复现 | **必须评估**忽略平移造成的误差 |
| 极姿态、真实关节活动边界、关节内部载荷 | **不能**把固定铰链结果直接当成动物结论 |

**若将来真做这一步的验证顺序**：先**固定骨长、核对旋转轴**，用目标步态**同时拟合骨段方向与足端轨迹**；只有当偏差**稳定且超出测量误差**时，才去查它是否来自关节中心迁移——**不得仅凭"脚轨迹拟合不好"就归因于缺平移**。

**若最终确需加入**：优先**随转角变化的受约束平移**，或有物理依据的**被动柔顺**；**不要**给策略一个独立、主动的伸缩轴——那会让它用伸缩腿补偿错误构型，反而更偏离巨蜥。

### 局部运动能力（不等于巨蜥目标动作已验收）

| 目标动作 | 判决 | 依据 |
|---|---|---|
| 外展姿态 | 局部可调，支撑未验证 | 零位外展；`haa` 可调股骨角，不证明四足承重或稳定性 |
| 前后摆动 | 方位可调，目标轨迹未验证 | `hip` 调腿平面方位，平面内各轴也可改变足端前后位置 |
| 膝屈伸 | ✔ | `hfe`；范围问题另计 |
| 足端调整 | △ 部分 | 单条局部 foot 轴；全腿同时满足位置与接触朝向尚未验证 |

## 证据引用

- 几何与断言（本次运行，2026-09-30）：`python rl_exp\tools\verify\check_leg_reachability.py --self-check`。输出含每腿零位脚掌原点、四分之一转后位置、五关节限位、脚板法线与倾角、**髋力臂**、膝共线角与越线量。自检断言的恒等式：零位 = 原点之和、髋转动绕髋轴、**髋不改变倾角**、机身抬高带动脚板、每关节 `dp/dq` = 自身力臂、**倾角只由折腿和决定**、`foot` 绕自身轴转法线。
- 力臂**口径差异（须记住）**：本工具自检的"hip lever"是**零位下髋轴到脚掌中心的垂距**（本次实测 lf 0.4679 / rf 0.4680 / rl 0.4513 / rr 0.4679 m）；`acceptance/records/2026-09-22-lizard2-stride-at-load.md` 里 `hip` 的 arm **0.490–0.494 m** 是**扫掠口径**。两者不是矛盾，引用时必须带口径。
- 脚板倾角单通道与立边：`acceptance/records/2026-09-29-lizard2-pad-leveling-unreachable.md`、`acceptance/records/2026-09-29-lizard2-pad-tilt-is-the-fold-sum.md`。

## 未覆盖边界

- **只做了轴级/骨段级映射**：没有在"几个代表姿态"（折叠、承重高度、前后极限）上复算——`fold_tilt_cos` 的恒等式与轴向不随姿态变，但**各关节在这些姿态下的实际作用量**未测。
- **"解剖对应"是功能推断**：依据是轴向与骨段位置，未与任何巨蜥关节角数据对齐（巨蜥侧无可用 ROM，且其运动学只到 8 kg）。
- 覆盖同型腿链的结构判读与四腿 FK 自检；未完成前后肢分别的解剖对齐、四腿代表姿态与动力学。胸/颈/尾和机体姿态也未纳入目标轨迹验证。
- 未做**动力学**验证：不回答"外展 vs 直立哪个更省或更承载"——那是本项第 ④ 步。
- 本记录不改任何资产、配方或限位。
