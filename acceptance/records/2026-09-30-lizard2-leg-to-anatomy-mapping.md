# lizard2 腿链 → 巨蜥解剖自由度：映射与结构差异（2026-09-30）

## 适用范围

把 `lizard2` 一条腿的五个关节映射到巨蜥后肢的解剖自由度，并逐个判定**哪些解剖动作本资产表达不了**。只做**轴级/骨段级**映射与结论；**不给**任何限位数值（那归 `work/active/joint-limit-shape-and-range-pass.md`），也不给生物限位（巨蜥无被动 ROM 数据，见 `2026-09-29-varanid-joint-range-of-motion-evidence.md`）。

## 验收条件

- 每条结论必须能追到 ① 资产轴向（URDF/generator）② 本仓工具的可运行断言 ③ 已成立的读数记录；**功能推断**（"这个关节相当于什么肌肉动作"）与**几何事实**分开写。
- 表达不了的解剖动作记为**结构差异**，并写明"为什么限位/参数解决不了"。
- 同一量在不同工具下口径不同时必须标出（本记录就有一处：髋力臂）。
- 不把跨物种趋势（Clemente 2011/2013，≤8 kg）当成本资产的角度依据。

## 结果

### 链条与共位关系（事实）

腿链自根向端：`hip` → `haa` → `hfe` → `kfe` → `foot`（五条轴的轴向见下：`generate_urdf.py:50` 与 URDF 实测）。`hip` 与 `haa` **同原点**（`hip` 是后加的 meshless 微链，各 0.05 kg）。骨段：`haa→hfe` 之间是股骨，`hfe→kfe` 之间是胫骨，`kfe` 之后是脚板。

| 关节 | 轴（base 系） | URDF 限位 | 决定哪一段的姿态 |
|---|---|---|---|
| `hip` | (0, 0, 1) 竖直、腿根 | ±0.60 | 整链绕竖轴在水平面扫 |
| `haa` | (−1, 0, 0) 横、与 `hip` 共位 | ±0.60 | 股骨在体侧平面内抬/落 |
| `hfe` | (−1, 0, 0) | ±1.20 | 胫骨相对股骨（同平面） |
| `kfe` | (−1, 0, 0) | ±1.60 | 脚板相对胫骨（同平面） |
| `foot` | (0, 1, 0) | ±0.50 | 脚板绕横向轴滚转 |

### 解析身份：脚板姿态只有三个轴（工具内已断言）

本仓工具给出并**在自检里断言**了这条恒等式：脚板姿态 = `Rz(hip) · Rx(σ) · Ry(foot)`，其中 **σ = haa + hfe + kfe**；`hip` 不改变脚板倾角（竖直轴不动法线的 z 分量），三铰链的**和**决定面内倾角，`foot` 只走 `cos(foot)` 一条通道。

⇒ 骨段级可分（股骨、胫骨各有自己的角），**脚板相对躯干**的姿态只由 σ 决定。

### 映射（几何事实 + 功能推断分开写）

| 机器人 | 解剖对应（**推断**，依据轴向与骨段位置） | 表达性 |
|---|---|---|
| `hip` | 股骨**前引/后缩**（retraction/protraction，跨步） | ✔ 可表达；本资产唯一前后自由度，力臂最大 |
| `haa` | 股骨**外展/内收** | ✔ 可表达，但只在体侧平面内 |
| `hfe` | 膝**屈伸** | ✔ 可表达（范围含 13.61° 反折，属**限位形状**问题，非表达性） |
| `kfe` | 踝**跖屈/背屈** | ✔ 可表达 |
| `foot` | 足端/脚板调整 | △ **部分**：倾角只有 `cos(foot)` 一条通道；无独立的足偏航 |

### 结构差异（限位与参数解决不了）

1. **没有股骨长轴旋转。** `hip` 与 `haa` 共位，二者只张开 **z 与 x** 两个轴；参考姿态下股骨指向体侧（≈ +y），所以"绕股骨自身长轴转"= 绕 **y**，**该位置没有 y 铰链**。整条腿唯一的 y 轴是远端 `foot`，**位置不同、买不到**。而巨蜥运动学明列 femoral rotation 参与步幅（`2026-09-29-varanid-joint-range-of-motion-evidence.md` §Clemente 2013）——**这是同一个"三平行铰链"的直接后果，不是限位画大了**。
2. **腿在髋之后是平面 3R 机构。** `haa`/`hfe`/`kfe` 同轴 ⇒ 膝、踝的摆动平面与外展平面**永远重合**；动物可以有"小腿平面相对外展平面转过一个角"的构型（正是长轴旋转买到的东西），本资产表达不了。
3. **无平移自由度。** tegu 的 XROMM 证据显示关节存在旋转—平移耦合（方法层面、非巨蜥数值）⇒ 纯转动铰链表达不了这种耦合。属结构差异。
4. **脚板姿态三铰链不可分**（σ 的和）：这是"关节耦合确实存在"的**实例**——但它是**脚板级**耦合；本项形状假设要的"盒允许但不可接受的那组角"**尚未给出**，故本条只作证据候选，不作结论。

### 对仿生目标四项的表达性判决

| 目标动作 | 判决 | 依据 |
|---|---|---|
| 外展支撑 | ✔ | 零位即外展姿态；`haa` 可调外展角 |
| 前后摆动 | ✔ | `hip`（唯一前后自由度） |
| 膝屈伸 | ✔ | `hfe`；范围问题另计 |
| 足端调整 | △ 部分 | 倾角单通道；无独立足偏航 |

## 证据引用

- 几何与断言（本次运行，2026-09-30）：`python rl_exp\tools\verify\check_leg_reachability.py --self-check`。输出含每腿零位脚掌原点、四分之一转后位置、五关节限位、脚板法线与倾角、**髋力臂**、膝共线角与越线量。自检断言的恒等式：零位 = 原点之和、髋转动绕髋轴、**髋不改变倾角**、机身抬高带动脚板、每关节 `dp/dq` = 自身力臂、**倾角只由折腿和决定**、`foot` 绕自身轴转法线。
- 力臂**口径差异（须记住）**：本工具自检的"hip lever"是**零位下髋轴到脚掌中心的垂距**（本次实测 lf 0.4679 / rf 0.4680 / rl 0.4513 / rr 0.4679 m）；`acceptance/records/2026-09-22-lizard2-stride-at-load.md` 里 `hip` 的 arm **0.490–0.494 m** 是**扫掠口径**。两者不是矛盾，引用时必须带口径。
- 脚板倾角单通道与立边：`acceptance/records/2026-09-29-lizard2-pad-leveling-unreachable.md`、`acceptance/records/2026-09-29-lizard2-pad-tilt-is-the-fold-sum.md`。
- 链条、共位、单位质量：`rl_exp/blender/generate_urdf.py:44-57`、`rl_exp/versions/lizard2/FAMILY.md`。
- 解剖侧 DoF 名称与"无被动 ROM"：`acceptance/records/2026-09-29-varanid-joint-range-of-motion-evidence.md`。

## 未覆盖边界

- **只做了轴级/骨段级映射**：没有在"几个代表姿态"（折叠、承重高度、前后极限）上复算——`fold_tilt_cos` 的恒等式与轴向不随姿态变，但**各关节在这些姿态下的实际作用量**未测。
- **"解剖对应"是功能推断**：依据是轴向与骨段位置，未与任何巨蜥关节角数据对齐（巨蜥侧无可用 ROM，且其运动学只到 8 kg）。
- 只覆盖**一条腿的几何**；四腿的镜像符号、以及机体姿态（胸/颈/尾）不在内。
- 未做**动力学**验证：不回答"外展 vs 直立哪个更省或更承载"——那是本项第 ④ 步。
- 本记录不改任何资产、配方或限位。
