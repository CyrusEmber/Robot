# lizard2 两脚承重与抬身能力测试方案

## 适用范围

用户要求为“两脚着地时，腿部与脚板能否把身体抬高”建立对应 work。本记录保存本次提出的测试方案，工作入口为 `work/active/lizard2-two-foot-body-lift.md`。本轮授权落盘计划，不启动仿真、训练或修改正式驱动。

分开回答受控承载抬身能力与自由机身步态协调。前者以当前双轴隔离候选为主、正式 v6 为对照；后者交既有学习步态事项使用匹配机体的实际策略。两脚先限定为左前＋右后、右前＋左后两组对角组合，不外推同侧、双前或双后支撑。失败定位不得恢复已撤销的手工步态交付前置。

## 验收条件

### 输入与实施前置

- 固定各自资产、质量、惯量、重力、物理步长、控制周期、摩擦、自碰撞设置、默认姿态、驱动类型、PD、限矩与限速，保存哈希和后端读回。正式 v6 沿用实际配置；候选新增轴沿用已测诊断值 Kp=400 N·m/rad、Kd=40 N·m·s/rad、上限70 N·m，其余沿用 v6。它们不是正式设计参数，不现场调参追求通过。
- 平地，无随机扰动。每种支撑姿态先用实际网格和限位检查几何可达、碰撞、尾部与非支撑足净空，形成完整关节目标。只在试验开始前初始化；计量阶段不得写根位姿、关节状态或自动重置。不能用只动膝肘而其他目标全零的指令代表协调伸展。
- 受控阶段使用只释放机身竖直平移的导向约束。明确约束连接体和坐标系，记录其完整反力/力矩；不能施加竖直托举或高度驱动。导向承担横向力和稳定力矩，因而可能减轻部分关节需求，结果只能归于该夹具工况，不能称整机自由双足能力已证。
- 在物理执行前落实夹具竖直反力容差、禁止接触/穿透、关节限位余量、速度、机身下沉、非有限值等停止条件，注明继承依据；没有定义就不运行。不把成功阈值当安全停止线。导向实现及采样正确性需有实际正反对照，不能仅凭配置声明。
- 本记录内数值是拟议诊断参数和工程判据，不是已有能力验收或硬件规格；实现前审查可达性与测量分辨率，任何必要修订应先更新方案及依据，再采样，不能按结果放宽。

### 受控测试矩阵与预算

| 支撑工况 | 必须满足的接地条件 | 抬高目标 |
|---|---|---|
| 四足基线 | 四足承重；尾、胸腹、头及其他非足部位不承重 | 先2 cm，再5 cm |
| 对角 A | 仅左前、右后承重 | 先2 cm，再5 cm |
| 对角 B | 仅右前、左后承重 | 先2 cm，再5 cm |

正式 v6 与候选分开执行、分开报告。高度以各工况稳定后的机身参考点为基准，同时观察胸腹及全身质心；脚的水平目标保持，机身沿竖直方向运动，腿部目标由协调的几何路径给出并核验实际动作权限和限位，脚掌维持该工况的贴地姿态。保留现有位置控制与零速度参考，不增加速度前馈。

每例静置5 s、平滑抬高2 s、保持2 s、回落2 s、恢复2 s。第一轮最多两个机体×三个支撑工况×两个幅度，共12例、计划物理采样156 s；每例一次，不自动重试。基线或初始支撑条件不成立时停止依赖该条件的工况；低幅失败不继续对应高幅。资源墙钟预算与夹具校验预算在实施前写入隔离配置；几何不可达记未执行及原因，不计为驱动失败。首轮不提供重复性或分布统计结论，复测需针对具体新证据或修复另定范围。

#### 足板单独抬身对照（2026-10-29 增补；同日预查后降级）

**降级说明**：离线预查（`2026-10-29-lizard2-foot-plate-sweep.md`）显示几何可达但 v6 驱动按静态估算力矩差约一个数量级，因此本对照不再跑物理，只保留预查结论；脚板关节是否必要改由 `work/active/lizard2-foot-plate-necessity.md` 承接。下文是增补时的原设计，保留作历史，不再是待执行项。

上述矩阵的抬高由肩/髋外展与肘/膝几何路径给出，足板只随动保持贴地；它回答不了“移动足板本身能否抬高身体”。增补一个独立对照：只驱动足板关节（`lf_wrist_joint`、`rr_ankle_joint` 或 `rf_wrist_joint`、`rl_ankle_joint`），其余关节目标固定在该工况已确定的受载初始化姿态，不叠加外展、肘膝或躯干动作；不与上表混报，也不把腿部协调抬身的结果算作足板能力。

- **目标定义**：只剩一个自由度，不能同时保持脚底接触点不动并升高机身，因此该对照允许足底在地面上滚动，目标以足板转角给出，机身升高量按实际足部碰撞网格最低点贴地的几何推算，不套用上表的“水平目标保持”。足板转角范围受关节限位 ±0.5236 rad 约束，预查需报告升高量随转角的函数、是否单调、是否在限位内出现穿地或非支撑部位触地；推算升高量低于测量分辨率则记不可达，不执行。
- **判据调整**：足部稳定一项改为报告接触点沿地面的滚动行程与压力中心，不用“水平漂移不超过5 mm”判通过；抬高、保持、指定支撑、载荷核对、恢复及停止线沿用上表。
- **驱动口径**：先按正式 v6 驱动原样执行（足板 Kp 约 12.2 N·m/rad、上限 70 N·m）。该刚度下足底对地力臂产生体重量级力矩所需转角可能远超限位，试验失败是可能结果；不为通过而加大足板 Kp、上限或预偏置，任何增益改变须另立说明目的与依据的对照，且不得写成 v6 通过。
- **解读**：抬高通过只说明该夹具与该驱动下足板可贡献的抬升；失败时区分转角到限位、力矩到上限、几何升高量不足、非支撑部位触地几类，缺可信力矩则只判动作；足板与腿部协调抬身的贡献不由本对照分离，需要时另设两者组合的对照。
- **预算**：沿用每例静置5 s、抬高2 s、保持2 s、回落2 s、恢复2 s，先2 cm；实际可达升高量不足2 cm时按预查可达量报告，不放宽幅度。每例一次，不自动重试。

### 观测与拟议判词

采集物理子步数据：全身质心、根和胸腹位置/姿态；全部关节目标、实际角度和速度；逐刚体地面滤波接触力；真实掌底姿态、材料点位移、接触点或压力中心；导向完整反力/力矩。约束或关节 wrench 不直接当电机力矩，须按已核动力学、轴向及其他贡献验证可归因性；implicit drive 的 shadow 或 Kp×误差不能当实测。实际力矩通道不可信时，动作可判，但饱和和余量保持未知。

| 项目 | 拟议判据/报告要求 |
|---|---|
| 抬高 | 保持末1 s平均升高不低于目标的90%；同时报告机身、胸腹与质心，排除旋转造成的假抬身 |
| 保持 | 同窗参考高度峰峰值不超过5 mm，并核实平均竖直速度和加速度近零后才采用静载判词 |
| 指定支撑 | 计量阶段指定足持续承重；非支撑足、尾及其他非足部位逐子步对地力模长低于1 N；非支撑足需有实际几何净空，不能仅用力阈值当离地证明 |
| 载荷核对 | 静止保持窗指定足平均法向力之和与实际重量差不超过5%；另核导向竖直反力接近零，不能仅凭足力和判断夹具无帮助 |
| 足部稳定 | 指定足参考点水平漂移不超过5 mm；同时核材料点、转角及接触分布，避免纯旋转/滚动漏检；无持续翻边或明显穿地，量化口径先落实现再采样 |
| 恢复 | 恢复末窗平均高度距起始稳定高度不超过5 mm；预期支撑恢复，无终止、重开或状态写入 |
| 驱动余量 | 对可信实际力矩及速度报告峰值、持续值、上限占比和限幅时间；只有动作通过且数据可信才能讨论该工况余量，贴上限完成不能写成余量充足 |

同帧力与物理子步时序保留，不将各足不同时间的历史峰值相加当体重。升降阶段用全身质心加速度解释力差，不能强行套静态力平衡。若接触分布、驱动输出或夹具反力无法可靠采集，逐项标未覆盖，不把未知填成零或成功。

采集器与复读判词需拒绝重置后高度跳变、尾部/夹具托举、漏掉一个承重点、历史峰值伪装同帧载荷等错误证据。若修复真实实现缺陷，回归验证修前失败、修后通过；本项不默认新增仓库闸门。

### 自由机身策略交接与归因

撤掉导向后，只使用与机体、动作和观测匹配的真实 checkpoint。由学习步态事项固定命令、窗口和样本预算，检查两组对角支撑的高度、脚板滑移/翻转、实际承重、接地冲击、限矩/限速和尾部辅助。未出现纯双足窗口时报告未覆盖，不虚构支撑阶段；候选无适配策略时保留在办，不用正式 v6 旧 checkpoint 判候选失败。

- 受控抬身通过而自由行走失败：有限夹具工况能力成立，平衡/协调与夹具替代的需求仍需区分。
- 受控失败且可信驱动持续限矩：支持该姿态与指令下驱动力矩受限，仍需排除不可达、碰撞或错误目标造成的顶死。
- 受控失败但未限矩：检查目标、PD、几何与接触约束，不直接加大上限。
- 靠尾部、其他部位或导向竖直力完成：不算指定两脚独立承重通过。
- 无可信力矩：只判动作与支撑，不判断力矩余量或电机不足。

用户要求做“两只腿能不能支撑身体”的实验，先检索复用已有事项，并明确“先更新再来”；经范围确认，选择先做受控承重，不直接做自由机身双足平衡。本次仅更新事项与方案，不改实现、不运行仿真、不训练，延续当前不提交的边界。

**当前输入与范围**：采用圆足事项 `work/active/lizard2-round-feet.md` 最新记录绑定的 `rl_exp/out/lizard2_round_feet/export03/lizard2_round_feet/lizard2_round_feet_repaired02.usda` 与对应 URDF、candidate、修正审计；26 个机器人活动轴、四个固定圆足体。球半径 0.08 m、每足 1.0861 kg 及实心球惯量仍为已授权诊断假设。其来源和实际接口检查见 `acceptance/records/2026-10-30-lizard2-round-feet-plan-review.md`，不将旧 v6/双轴或原失败 USD 混作当前输入。若夹具另增一个竖直被动关节，机器人仍为 26 轴，夹具轴不加入策略动作。

本轮仅准备左前＋右后、右前＋左后两个独立静态承重工况，不包含抬高、回落、踮脚、增益扫描、训练或旧双机体对照矩阵。需要四足基线时仅为初始化/测量诊断，单列目的和预算。导向约束仅释放机身竖直平移，不设高度驱动；它提供横向与转动帮助，可能减轻关节负担，因此即使通过，也只能写“该导向工况下指定双足承担机体重量”，不能写自由平衡、自然步态或实物能力通过。

**旧证据复用边界**：`2026-10-29-lizard2-preload-offset-control.md` 已记录旧正式 v6 掌部机体、左前＋右后、竖直导向及手工预偏置下的 2 s 保持和 0.02/0.05 m 完整升降；这纠正了事项仍只描述早期早停的滞后状态，但不是圆足或另一组对角通过。旧导向、子步采集、配对绑定和复读可按受影响切片复用；旧目标偏置、平掌法线、根高、非支撑足净空及成功读数不直接移植。旧缺证矩阵、恢复和自由基座交接保留在活跃事项，不因缩小本轮范围而取消。

**实施前必须完成的最小准备**：

1. 用共享 FK/IK 为球面最低点贴地重新求两组静态姿态，报告关节余量、球心位置和其余足/尾/胸腹/头实际几何净空。候选自碰撞保持关闭，内部相交记模型限制，不重启旧脚板碰撞修形；地面碰撞、限位及外部净空必须核。静态节点检查不冒称连续切换路径验证，本轮可分别初始化两组工况，不要求手工从四足移重成功。
2. 从已修正圆足 USD 新建隔离导向装配，保留全部机器人质量惯量，复核夹具无竖直驱动/托举及其反力读回。单刚体旧导向自由落体正反例不单独证明新机器人装配无帮助；结合新装配约束、反力和载荷核对验证，不搭建与本次无关的新夹具项目。
3. 复用逐物理子步具名地面接触配对，覆盖指定足及所有潜在其它承重点，保存同帧地面力而非历史峰值；同时记录根/胸腹/全身质心位置与速度、足心及姿态、关节目标/实际/速度、导向完整反力和力矩。读取当前足—地材料与接触偏移，不能以视觉颜色代替物理材料。实际驱动力矩若无可信通道，只将饱和、余量和电机不足标未知，不把完整力矩遥测建设作为静态承重判定的无关前置。
4. 将沉降与保持窗、静态速度/高度稳定和载荷判据、非指定部位承重/净空、导向竖直帮助容差、限位/速度/下沉/非有限停止线、每例次数及总墙钟预算落入隔离配置后集中确认。本记录上文旧 13 s 升降时序、12 例矩阵及旧数值均不是圆足已批准协议；原脚本默认停止线也不自动套用。缺输入不运行，不从结果倒推阈值。
5. reset 后核真实初始化并处理/下发当前工况目标，再推进物理；接口检查已证明本 fork reset 后旧 backend target 可以残留，不能只看 action 缓冲清零。采样阶段禁止写根/关节状态、自动 reset 或任何竖直高度驱动；失败帧先保存再停止。两组独立判定，一组物理失败不自动取消另一组；共用前提失败时说明依赖未执行。初轮保持既有驱动，不自动加增益、限矩或套用旧预偏置；必要目标偏置另列为诊断对照，经依据与预算确认再做。

**判词与后续**：只有稳定窗口内指定两足持续承担近体重载荷、其它部位无承重且有净空、导向没有可见竖直托举，才能按明确容差判本工况承重；载荷差同时结合质心加速度解释，不能以两足力和单独证明夹具无帮助。失败分别检查下沉、目标/姿态、额外接触、限位和测量，不直接归因电机不足；缺测则未判。自由双足平衡交 `lizard2-learned-gait`，抬身/恢复等历史未完动作仍由本项维护，恢复须另定范围；此修订不是关闭审核。
