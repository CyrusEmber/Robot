# 工作集账本试点：迁移后读数与人工审查（after）

## 适用范围

本记录 = `2026-09-20-doc-read-cost-baseline.md` 定的同一任务（定位一个未完成事项，报出状态、
规则落点、关闭条件）在**迁移后**的同口径重做，加上三个试点事项的**人工审查**结果。
**读取成本是附带收益**；主判据是事项是否**可定位 / 可执行 / 可关闭**（`WORK_PLAN.md` §9）。
不外推其它任务类型，也不外推全仓。

**本试点于 2026-09-20 收尾**：三项质量判据通过（走查真抓出 #6 的框架继承链遗漏并已修）。
**扩大迁移不在本项范围内**，另开独立事项 `work/active/ledger-migration-expansion.md`（批 1 HARNESS →
批 2 PLAN → 批 3 ACCEPTANCE，一批一验收），本记录不再追加范围。

## 验收条件

与基线记录完全一致（迁移前固定，未事后调整）：计数单位 = 读工具返回内容的 UTF-8 字节，
重复计入，入口声明的必读文件按整份计；步骤 S1 读入口 → S2 定位 → S3 读该事项 → S4 核对落点 →
S5 报三项；③ 漏掉有效约束 ⇒ 失败并停止扩大迁移；② 如实记录、不作主判据。

### ③ 是否漏掉完成任务所需的有效约束 —— 人工审查（主判据）

| 项 | 判定 | 依据 |
|---|---|---|
| **可定位** | ✅ | `--list` 一行给 id/状态/范围/下一步；`--locate` 一次命中事项文件；工具输出自称"已迁移 N 项"，不冒充完整待办 |

**闸门只验字段与存在性**；上面每一项都是**沿着"下一步 → 观测 → 分支结论"真走了一遍**得到的判定。
