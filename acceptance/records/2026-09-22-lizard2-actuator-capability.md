# 2026-09-22 lizard2 执行器响应曲线（修正版：力矩估算符号与"悬空"口径均已更正）

## 适用范围

- 被验对象：`Lizard2-Flat-Play-v1`（30 关节、implicit PD、`legs` Kp 800 / Kd 40 / effort 180）。
- 工具：`rl_exp/tools/verify/check_actuator_budget.py`，两层：
  **unloaded**（`cfg.sim.gravity=(0,0,0)`，只驱动**一个**指定关节，其余关节**保持在起始参考姿态**）；
  **loaded**（重力开、放在平面上、四腿划水，读机体前进速度）。两层都走**部署动作接口**下发。
- 覆盖：单关节跟踪能力随频率的变化、生效限幅、负载下"划水"能给多少速度。
- 不覆盖：真步态（划水不是步态）、接触/滑移、策略能否学会用满包络、以及多腿耦合。

## 验收条件

- **力矩符号必须与执行器模型一致**：`tau = Kp*(target - q) - Kd*qd`（第一版写成 `q - target`，
  滞后时 P 与 D 会**相加**，把 0.5 Hz 的估算从 12.4 抬到 163 N·m）。
- **"悬空"必须是真无载**：关重力、只动一个关节、其余保持固定参考（第一版是"每步把落定位姿写回"，
  重力与地面接触都还在，且驱动了四条腿而只记一条——那不是悬空单关节测试）。
- 惯性需求 `I·A·(2πf)²` 与跟踪误差**分开报**：前者是轨迹有多重，后者是伺服跟不跟得上。
- 力矩只能给**估算**：`applied_torque` 对 implicit 执行器结构性为零（`parkour_mdp.py:275`）。
- 不得由 `effort/velocity` 推出"速度上限"：限幅作用于**合成**力矩，P 项可以抵消 D 项。

生效限幅（建成环境实测）：`legs` 16 关节 Kp 800 / Kd 40 / **effort_limit_sim 180 N·m** /
**`velocity_limit_sim=None`**（cfg 的 10 rad/s 被本 fork 丢弃，`actuator_pd.py:80-91`）；`feet` 200/12/70；`spine` 400/20/80。

**loaded（四腿划水）**：0.50 Hz +0.074、1.00 +0.057、**1.50 +0.491**、2.00 +0.243、2.50 +0.300、
3.00 +0.002 m/s（均值；非单调，像共振带）。它不是步态，只作下界。

**能读出来的（修正后）：**

1. **跟踪随频率平滑退化**：0.5 Hz 时 rms 为幅值的 **9%**，1 Hz **18%**，2 Hz **35%**，3 Hz **50%**。
   "干净跟踪到 0.5 Hz"是**严格判据**（rms<20% 且超差步<10%）的结果，不是能力悬崖。
2. **力矩在这些频率下并不吃紧**：PD 估算 3 Hz 也只有 **74.8 N·m**（限幅 180）。
   ⇒ 先前"0.5 Hz 就 163 N·m / 限幅被 Kd·qd 吃掉 / 纯摆动速率上限 4.5 rad/s"**全部撤回**（符号错 + 由合成限幅反推速度上限，两处都错）。
3. **惯性需求一列在 2.5–3 Hz 超过 180**（232 / 335 N·m），但它是单半径估算（I≈1.57）且此时跟踪误差已达 43–50%
   ⇒ 两列都不可当作"惯性真的超了"的证据；只能说"这个幅度在 3 Hz 已明显跟不上"。
4. **单髋全幅 ±0.6 rad 正弦的频率能力**：约 1 Hz 时 rms 18%（尚有 82% 幅度跟随），2 Hz 起明显落后。
   按步幅算术（0.55 m ≈ 全幅 × 力臂 × 2），若**全部**步幅来自单髋一个全幅摆动，1 Hz、duty 0.5 ≈ 1.1 m/s；
   但这只是"单关节轨迹"的换算，**不构成对 0–3 窗口上界的判决**，也没有据此调整执行器参数。

## 未覆盖边界

- **力矩是估算**：不含求解器隐式项；"不高"这个结论的证据是估算值与跟踪误差两条曲线一致，不是读到的力矩。
- **unloaded 只有一条关节、其余静止**：不含多腿耦合与躯干助推；真步态可以用躯干做功把速度推得更高。
- **loaded 是划水**：0.49 m/s（1.5 Hz）是下界，不能当可达速度；3 Hz 归零说明该运动在该频率下失效。
- **未调任何执行器参数**（所有者要求）：窗口与执行器都不因本记录改动。
- 单半径惯量估算、时间步敏感性、超调/稳定时间未单独列（当前只有 rms/峰值）。
