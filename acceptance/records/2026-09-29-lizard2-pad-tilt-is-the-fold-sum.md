# 脚掌倾角就是折腿和：|SIGMA| 复现实测倾角，脚板行程买不到它；顺带量到 hfe 的 13.6° 反折（2026-09-29）

## 适用范围

- 被测对象：`logs/rsl_rl/lizard2_v2/2026-09-28_17-02-42/model_9999.pt` 的评测帧记录
  `ablation_harness/results/lizard2_flat_v4/v2/Lizard2-Flat-v2_9999_deterministic_seed123_joints30/eval.frames.pt`
  （`baseline-frames-3`、1000 步 × 256 envs、seed 123、20 s），与
  `2026-09-29-lizard2-pad-leveling-unreachable.md` 的探针读数（同一 checkpoint、1 env/档、定点 0.5/1.5/2.8）对照。
- 该问的由来：那条记录把结论收窄到"固定该帧小腿朝向、只动踝角"的可达集，并写明整腿可达性未做。
  本记录做的是更小的一步：**倾角本身是什么量**，以及它能否从已有帧记录里算出来。
- 不覆盖：世界倾角的重算（格式 3 无姿态列）、承重/平衡/能否站稳、需求与容差、奖励设计。

## 验收条件

1. 恒等式必须对**暴力 FK** 断言，不能对自身；断言须用**良态量**（法线 z 分量），不能用 `acos` 的结果
   （P010：一阶量、派生量不是量）。
2. 对照必须是同口径：承重帧（接触法向力 > 1 N）、中位对中位，且**两侧的读法要写明**——
   `SIGMA` 是机体系量，探针记录的倾角是世界量 ⇒ 机体/胸腔姿态落在差额里。
3. 断言的几何事实要**钉住资产**：动 URDF 或换资产必须让断言响，而不是让数值悄悄变。
4. 数值只在本记录；事项与其它文档留指针。

## 结果

### ① 恒等式（自检里逐位验证）

腿链 `hip(Z) → haa(−X) → hfe(−X) → kfe(−X) → foot(+Y)`（`lizard2.urdf:415,422,429,436`），三个铰同轴可加，
脚板 link 相对机体的姿态 = `Rz(hip)·Rx(SIGMA)·Ry(foot)`，`SIGMA = haa + hfe + kfe`
⇒ 机体水平时，脚掌法线相对机体竖直的倾角只由这三个数决定：

```
cos(tilt) = ny·sin(SIGMA) + (nx·sin(foot) − nz·cos(foot))·cos(SIGMA)     (nx,ny,nz) = 该腿脚垫法线
```

三条推论，全部在 `check_leg_reachability.py --self-check` 里断言（不是散文）：

- **髋不进这个式子**：绕 z 转不改变法线的 z 分量 ⇒ 同样的 `SIGMA`，髋角 0.11 与 −0.4 给出逐位相同的倾角。
- **`SIGMA` 怎么分配也不进**：`(0.62, 0, 0)` 与 `(0.207, 0.207, 0.207)` 给同一倾角 ⇒ 倾角不是任何单个关节的功能。
- **脚板行程买不到它**：式子只通过 `cos(foot)` 进，`SIGMA = 0.62 rad` 时整段 ±0.5 rad 行程的最低倾角仍 > 30°；
  且四条腿的脚垫法线拟合值都偏在 **±y**（`+0.0254 / −0.0254 / −0.0254 / +0.0254`，即离 link −z 1.45°）
  ⇒ `nx ≈ 0`，式子里对 `foot` 取极值的位置就在 **foot = 0**：**这只脚板越动越糟，不动最好**。

| 快 | lf | 27479 | 12.6 / 15.6 | −14.8 / −5.9 | 11.2 | 1.48 |

**读数**

1. **rr / rl / rf 三腿三档，`|SIGMA|` 复现实测倾角到 1–3°**（最大差 3.3°，rf 快档 33.1 vs 36.4）
   ⇒ 倾角就是折腿和这一个标量。它是"姿态"的读数，不是某个关节或某条轴的故障。
2. **lf 是唯一 `SIGMA` 小的腿**（慢档 1.7°，实测倾角 1.46°）⇒ **这套链与这套限位做出过平放**。
   三条腿 40–50° 是**姿态选择**，与那条记录自己的收窄（"可达性未算，不能说结构不可行"）同向，且比它更进一步：
   不必等可达性扫描，平放已经被现成策略做到过。
3. **脚板不是这条链的短板**：实测 foot 行程 p50 ≤ 3.7°、p95 ≤ 5.8°（rr/rl），钳位在 0 附近
   ⇒ "给脚板更多权限/更大行程/更弱的增益"都不可能改变一个 `|SIGMA|` = 40° 的倾角（与记录 ⑤ 的 1–3° 同向，机制更硬）。
4. **一条没关掉的口子**：lf 的中/快档 `|SIGMA|` 7.9/12.6° 而探针的世界倾角仍是 1.46°
   ⇒ 差额只能来自机体/胸腔姿态（前腿挂在 `chest_pitch` 上，`chest_pitch` 实测 14.8–21.6°；`spine_leg_coupling` 0.78–0.81）
   ⇒ **可证伪**：若前对的世界平放是脊柱在补，则前腿的机体系折腿随速度涨而世界倾角不涨。要判它必须有带姿态列的读数。

### ③ 连带量到的几何事实：hfe 的限位越过膝伸直位

三铰同轴 ⇒ "伸直"是 `hfe` 把大小腿转成共线、**不是零位**（零位本身已弯），所以"限位有没有越过伸直"必须逐腿算。
逐腿数值、网格止挡与行为读数归 `2026-09-29-lizard2-hfe-knee-limit.md`（它同时更正了 pad 记录的 hfe 行），
取值与是否重训归 `work/active/hfe-extension-stop-not-validated.md` —— 本记录不复述那批数。

本记录在这件事上只留两样：**这条几何现在被离线断言钉住**（`check_leg_reachability.py` 的 `straight_hfe` /
`thigh_shank_angle` / 逐腿 `KNEE_FACTS`，自检里逐腿对表 ⇒ 换资产或手改 URDF 会让它响），
以及它在倾角问题里的位置：**它和倾角无关**（倾角看 `SIGMA`，不看单关节），但它必须在上游任何
"把 ±1.2 当设计约束"的可达性研究之前定掉，否则可达集被那 13.6° 不可能运动撑大。

### ④ 那处 −0.126 rad 的出处（本轮要查的那一格）

`2026-09-29-lizard2-pad-leveling-unreachable.md` 给 lf 的"最优脚板角 p50 = −0.126 rad"，与本轮实测的 lf 脚板角
p50 = **−6.9° = −0.120 rad**（慢档）几乎相同，而四条脚垫法线的自身偏移只在 **±y**（∓1.45°）——式子里对 `foot`
取极值的位置仍是 **foot = 0**。⇒ 那个"最优点"不是网格常数，而是**随该帧机体/胸腔姿态移动的 argmin**
（姿态进 `nx`），其值因此贴近策略自己的动作；**不动的是下界**——任何 `foot` 都压不掉的那部分 `SIGMA`。
先前"−0.126 与拟合 1.45° 矛盾"的怀疑据此收回：两者不是同一个量。

## 判定

1. **脚掌倾角 = 折腿和（一个标量）**，并已被同一颗 checkpoint 的实测倾角复现 ⇒ `pad` 那条事项的
   "踝轴选错"不是倾角的根因：换轴（或加一条踝自由度）只是**再加一条把 `SIGMA` 归零的路**，
   而这条路现有三个铰已经走通过（lf）。
2. 因此需求侧的写法应当改：**判据要写 `SIGMA` 的容差**（可从帧记录直接算、零资产、零新关节），
   而"脚垫能否平放"是它的推论。世界平放另需一条（机体与胸腔的 roll/pitch 在容差内），也已可测。
3. `hfe` 的 13.6° 反折是**真缺陷**（沿用旧轴的限位、零位已弯），但它不解释当前症状；
   它与"髋行程在 2.8 档吃满"（`stride-axis-range-vs-speed`）同属**要动资产**的那一类，应当同一次换代决定。
4. 未关：世界倾角 − 机体倾角 的差额（lf 中/快档 5–10°）。补法只有两条——给帧格式加一列姿态，或跑一次探针。

## 未覆盖边界

1. **世界倾角未重算**：格式 3 里"姿态故意不是一列"（`ablation_harness/baseline_frames.py`），
   所以本文的预测都是**机体水平**口径；③④ 里"姿态那一项"的大小是从别的读数推的，不是本轮测的。
2. **两边的命令抽样不同**：探针是定点 0.5/1.5/2.8、1 env/档；本轮是 0–3 区间、256 envs ⇒ 是同一策略的**分布对照**，
   不是同一批帧；带是按本轮记录自己的 `command_world` 切的。
3. **比的是分布不是配对**：两侧都是中位，逐帧配对需要世界倾角那一列。
4. **跨 checkpoint 复核做不了**：v1 那份帧记录是 `baseline-frames-1`（无关节列），工具按设计拒绝读它。
5. 单 checkpoint、单 seed；不含承重、平衡、能否站稳（本记录只谈几何）。
6. 脚垫法线是**拟合值**（最低 2 mm 带的最小方差方向，双向 1.45°）：±2° 以内的比较不作数，
   而本文的核心比较是 40° 对 1–3°。
