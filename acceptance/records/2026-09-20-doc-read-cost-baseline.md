# 文档读取成本基线（before）

## 适用范围

只覆盖一类任务：**定位一个未完成事项，并报出它的状态、规则落点、关闭条件**。
代表任务 = `ablation_harness/HARNESS.md` 挂账 **#6**（`--headless` 已弃用而本仓仍在用）。
适用时点：2026-09-20 的文档结构（`work/` 与 `acceptance/records/` 尚未启用）。
不外推：不覆盖改代码、改闸门、开新版本、追历史证据等任务类型；不外推其它事项。

## 验收条件（迁移前定，不在事后调整）

计数单位与步骤固定如下，迁移后按**同一口径、同一任务、同一完成条件**重做一次。

- **计数单位**：读工具返回的文件内容 UTF-8 字节；命中行按整行计；重复读取每次计入；
  工具调用参数与路径名不计。**入口文档声明"必读"的文件按整份计**（不论读者跳读多少）——
  否则数字取决于读者的懒惰程度，不可复现。
- **步骤**：S1 读入口文档 → S2 按入口/规则给出的定位手段找到该事项 → S3 读该事项所需范围 →
  S4 核对机制落点 → S5 报三项。
- **三项输出**：(a) 状态判定与依据；(b) 规则落点；(c) 未完成动作与关闭条件。
- **通过标准**：③ 是否漏掉完成任务所需的有效约束 —— (a)/(b)/(c) 任一答不出、或依据找不到锚点
  ⇒ **判失败，不再扩大迁移**；② 读取总字节下降（不设百分比门槛，首次对照只用于决定是否继续）；
  ① 静态体积仅作背景，不作为通过量。

## 结果（before，2026-09-20）

① 静态体积（字节）：`FILEMAP.md` 85821；`ablation_harness/HARNESS.md` 27546；`README.md` 14011。

② 实际读取内容总量 —— 两条路径分别计：

| 路径 | 读取内容 | 字节 |
|---|---|---|
| **P1 按现制入口** | `README.md` 全文 | 14011 |
| | `FILEMAP.md` 全文（`README.md:6` 声明"新协作者/下一个 AI 必读"） | 85821 |
| | `HARNESS.md` 63–74（挂账 #6 行及邻行） | 7057 |
| | `ablation_harness/run_ablation.py` 75–119（核对 `:83`/`:115` 透传） | 2058 |
| | **合计** | **108947** |
| **P2 纯检索** | `--headless` 全仓命中：35 行 / 24 文件（命中行整行计） | 4082 |
| | `run_ablation.py` 75–119 上下文（命中行重复计入） | 2058 |
| | **合计** | **6140** |

③ 有效约束是否齐全（现状）：

- (a) **答得出**。依据就在 `HARNESS.md:73`：事项未改，理由是"删掉它是否等价取决于任务 cfg 是否启用
  visualizer（config visualizers 启用时要用 `--viz none` 才强制 headless），未确认前不动"。
- (b) **答得出**。落点 = 调用点 `run_ablation.py:83`/`:115`，加命令示例侧 `README.md:223`、若干 skill、
  vN NOTES（检索命中清单即这些）。
- (c) **答不出**：事项只写"未确认前不动"，**没写确认动作是什么、由谁确认、什么条件下算确认完**
  ⇒ 关闭条件不可判定，这是本次实测发现的真缺口。

结论：③ 在 (c) 上已经不齐（这是 before 侧的既有缺陷，不是迁移引入的）；② P1 = 108947 字节、
P2 = 6140 字节 —— **两条路径差 17 倍**，说明这个结构里最大的成本不是文件体积，而是
"入口声明了必读的大文件 + 没有定位工具"；若读者只靠检索，迁移能省的幅度很小。
撤换与否以 ③ 为否决项、以 ② 按 P1 为准（P2 同时报告，不取平均）。

## 证据引用

- 字节数来源（可复测）：`powershell -Command "Get-Item <path> | Select Length"` 与逐行
  `[System.Text.Encoding]::UTF8.GetByteCount()` 求和；检索命中用
  `Select-String -Pattern '--headless' -SimpleMatch` 对 `rl_exp/`、`ablation_harness/`、`README.md`、
  `.codemaker/`（排除 `results`/`archive`/`verify_logs`）。
  ⚠ 注意：`Get-Content` + `String.Length` 数的是**字符**不是字节，中文件会低估约 1.4 倍（本记录首次
  测量即如此，已改按 UTF-8 字节重测）。
- 关键行：`README.md:6`（FILEMAP 必读声明）、`HARNESS.md:73`（事项 #6 原文）、
  `run_ablation.py:83`/`:115`（透传点）。
- 相关：`WORK_PLAN.md` §9「条款：实际成效验证」。
