# 论文总结格式模板

## 一、12 点结构化字段表

以表格输出，字段顺序固定，一行一字段：

| 字段 | 填写指南 |
|---|---|
| 链接 | arXiv abs 链接（先核对 ID 与标题一致，不符要纠错） |
| 论文名 | 完整英文标题，含副标题 |
| 年份 | 首发/发表年份，附 venue（会议/期刊，Oral/Spotlight 可注明） |
| 方向 | 一级技术方向，英文短语，如 Multi-behavior Locomotion |
| 核心问题 | 论文解决什么问题，一句话说清痛点 |
| 核心方法 | 关键技术路线，列出核心机制/创新点，多个用顿号隔开 |
| Input | policy/系统的输入：状态 + 指令，概括来源即可 |
| Output | 输出粒度：关节力矩/关节位置/高层动作指令 |
| Policy | 单策略/多策略/分层；训练范式（RL/IL/蒸馏/端到端）；仿真环境 |
| Perception | 感知模态：proprioception / 视觉 / 深度 / 外感受，注明"无视觉"等关键取舍 |
| 能力 | 实际演示的行为与泛化表现，逐项列举，不夸大不脑补 |
| Game Friendly | 高/中/低 + 一句话理由，评级标准见下 |
| 我的结论 | 对当前游戏项目的可借鉴点与取舍，一两句话 |

### Game Friendly 评级标准

- **高**：方法可直接落地游戏 locomotion/动画/角色控制（如 motion matching、状态机可直接复用的结构）。
- **中**：理念可借鉴但需大改造，或依赖真实物理/sim-to-real 流程，游戏只需其骨架。
- **低**：纯机器人学/硬件导向，游戏仅可参考思想。

## 二、详细总结结构（六段）

1. **背景与动机**：领域现状、痛点、论文要解决什么。
2. **方法详解**：核心机制拆解，必须写到可复现粒度，逐项覆盖：
   - **训练管线**：分几阶段（如 teacher RL → student 蒸馏），每阶段输入/损失/算法；
   - **观测空间**：逐项列出本体感知、外感受、指令、特权信息各通道，采样细节（如高度采样点数/半径）能查到就写；
   - **动作空间**：输出什么粒度（力矩/关节位置/相位残差等结构化参数）；
   - **reward**：逐项列举任务项与正则项，不写"等若干项"；
   - **噪声与随机化**：逐项列出——物理参数随机化、观测噪声（哪些通道、什么形式、什么作用域）、初始化随机化、外感受退化模拟（如遮挡/漂移/失效三档条件及比例）、退火与课程策略；
   - **网络结构**：encoder/policy 模块构成与尺寸；
   - **curriculum**：地形课程、噪声课程、reward 权重课程各是什么。
3. **实现与部署细节**：仿真器、算法、并行规模、控制频率、机器人平台、传感器、关键工程点。
4. **实验与泛化结果**：主要结果（数字优先）、零样本泛化场景、对比基线、消融。
5. **局限与风险**：论文自述 + 读者视角的弱点。
6. **对游戏开发的启示**：结合 Game Friendly 评级，落到具体可借鉴点与"不该照搬什么"，与"我的结论"呼应。

> 方法段宁细勿粗：训练配方、噪声模型、reward 项是后续复现与借鉴的直接依据，论文正文/附录给出的都要收录；宁可长，不可糊。

## 三、写作规范

- 中文为主，术语保留英文原词（gait、policy、reward、domain randomization 等）。
- 每段聚焦事实，评价集中在"局限"与"游戏启示"两段。
- 不编造数值：网络尺寸、速度上限、训练时长等没核实到就写"待核实"。
- 引用论文措辞的关键概念时保留英文原名，如 Multiplicity of Behavior (MoB)。
